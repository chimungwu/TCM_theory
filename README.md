# 中醫生理病理學

> 模仿現代醫學「生理病理學」之體系，以《黃帝內經》原文為主軸，
> 涵蓋衍伸的疾病、症狀、治則、用藥（《神農本草經》、《湯液經法》）。

以 [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) 建置，
經 GitHub Actions 自動部署至 GitHub Pages。

---

## 體系設計

主題頁依類別性質採不同結構。**基礎物質**與**臟腑**兩類採「生理 → 病理 → 臟象 → 治則 → 方藥」五區塊：

| 區塊 | 內容 |
|---|---|
| 一、生理 | 主題之常態（生成、運行、功能） |
| 二、病理 | 主題之失常（虛實寒熱、出入升降） |
| 三、臟象 | 與五臟、六腑、經絡（是動病・所生病）對應 |
| 四、治則 | 依病態分立之治療大法 |
| 五、方藥 | 《本經》藥物 + 《湯液經法》組方邏輯 + 仲景延伸 |

**病因、病機、疾病、治則**四類以「概念 → 分類／機理 → 治則方藥」為骨幹；**經絡**按「循行 → 是動病 → 所生病」展開。

詳見 [docs/about/設計理念.md](docs/about/設計理念.md)。

## 內容範圍

七大類主題頁已全部完成：

- **A. 基礎物質**：氣 / 血 / 津液 / 精 / 神
- **B. 臟腑**：五臟（肝心脾肺腎） / 六腑 / 奇恆之腑
- **C. 經絡**：十二正經 / 奇經八脈
- **D. 病因**：六淫 / 七情 / 飲食勞逸 / 痰飲瘀血
- **E. 病機**：邪正、陰陽、升降、十九條、病傳
- **F. 疾病**：《內經》專篇所及之病證
- **G. 治則**：求本、正反、三因、八法等

另收《黃帝內經》高頻引用 33 篇原文（素問 25、靈樞 8），含篇旨與素問各篇王冰注。

## 本地開發

### 安裝

```bash
pip install -r requirements.txt
```

### 啟動本地預覽

```bash
mkdocs serve
```

開啟 <http://127.0.0.1:8000> 即可。

### 本地建置（不部署）

```bash
mkdocs build
```

產生 `site/` 目錄。

## 部署

推送到 `main` 分支，GitHub Actions 會自動執行 `mkdocs gh-deploy`，部署到 `gh-pages` 分支。

於 repository 設定 → Pages → Source 選擇 `gh-pages` 分支即可。

## 貢獻指引

### 新增主題頁

1. 找到對應分類目錄（例：`docs/主題/臟腑/五臟/`）
2. 複製 [docs/參考/模板.md](docs/參考/模板.md) 內容到新檔
3. 按模板逐步填入內容（模板為基礎物質／臟腑類之五區塊式；其餘類別請參照同類既有頁面）
4. 末尾標籤從 [設計理念](docs/about/設計理念.md#標籤系統) 之固定詞表選用
5. 在 `mkdocs.yml` 之 `nav:` 中加入該頁

### 引文格式

詳見 [docs/參考/引文體例.md](docs/參考/引文體例.md)。要點：

- 篇名全稱，不簡寫
- 原文用 blockquote (`>`)
- 王冰注緊接原文之下
- 仲景延伸內容必須明確標示「延伸」
