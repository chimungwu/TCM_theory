# 中醫生理病理學

> 模仿現代醫學「生理病理學」之體系，以《黃帝內經》原文為主軸，
> 涵蓋衍伸的疾病、症狀、治則、用藥（《神農本草經》、《湯液經法》）。

## 凡例

- **底本**：王冰次註本《重廣補注黃帝內經素問》與《靈樞》
- **註家**：王冰為主，選收主要註家（馬蒔、張介賓《類經》、張志聰《集註》、丹波元簡《素問識》等）
- **方藥本體**：《**神農本草經**》（藥物氣味、三品、主治）
- **組方邏輯**：《**湯液經法**》（藉《輔行訣》復原）五味補瀉
- **延伸**：仲景經方、後世名方明確標記為「**延伸**」
- **引文**：純原文加註，不附白話翻譯
