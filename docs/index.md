# 中醫生理病理學

> 模仿現代醫學「生理病理學」之體系，以《黃帝內經》原文為主軸，
> 涵蓋衍伸的疾病、症狀、治則、用藥（《神農本草經》、《湯液經法》）。

---

## 體系架構

每一個主題自成一篇，篇內固定五區塊：

<div class="grid cards" markdown>

-   :material-leaf: **一、生理**

    本主題在常態下的生成、運行與功能。

-   :material-fire: **二、病理**

    本主題的失常形態：虛實寒熱、出入升降。

-   :material-circle-multiple-outline: **三、臟象**

    與五臟、六腑、經絡（是動病・所生病）之對應。

-   :material-compass: **四、治則**

    依病態分立之治療大法。

-   :material-flask: **五、方藥**

    《神農本草經》代表藥物與《湯液經法》組方邏輯，並延伸仲景經方。

</div>

## 凡例

- 底本：**王冰次註本**《重廣補注黃帝內經素問》與《靈樞》
- 引文：純原文，註以王冰為主，選收主要註家（馬蒔、張介賓《類經》、張志聰《集註》等）
- 方藥：藥物以《**神農本草經**》為本體，組方以《**湯液經法**》（藉《輔行訣》復原）五味補瀉為邏輯
- 仲景方屬延伸內容，明確標記為「**延伸**」

詳見[設計理念](about/設計理念.md)與[引文體例](參考/引文體例.md)。
