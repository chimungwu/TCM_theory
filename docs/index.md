# 中醫生理病理學

> 仿現代醫學「生理 → 病理 → 診 → 治」之分科架構，以《黃帝內經》原文為主軸，
> 將散見全篇之中醫理論重新編排為**結構化、可主題反查、雙向跨參之索引**。
>
> 底本採王冰次註本《素問》《靈樞》，《素問》原文逐句附**王冰注**；
> 方藥本《**神農本草經**》之氣味三品、《**湯液經法**》之五味補瀉（藉《輔行訣》間接復原）；
> 「**延伸**」之範圍與用意——以《**傷寒論**》《**金匱要略**》仲景經方為延伸之主體，上承《內經》之理法、下開後世方論之祖；旁及歷代名方擇要：**唐**之孫思邈《千金要方》《千金翼方》、王燾《外臺秘要》（藥味精博）；**宋**之《太平惠民和劑局方》（成方廣傳）、嚴用和《濟生方》、陳自明《婦人大全良方》、錢乙《小兒藥證直訣》；**金元四大家**——劉完素（河間）主清熱、張從正（子和）主攻邪、李杲（東垣）主補土、朱震亨（丹溪）主滋陰；**明清**之張介賓《景岳全書》、王肯堂《證治準繩》、吳謙《醫宗金鑑》、葉天士《溫熱論》、吳鞠通《溫病條辨》、王清任《醫林改錯》（活血化瘀之發揮）等。
>
> 後世發展之**辨證框架**——**六經辨證**（仲景之發揮）、**八綱辨證**（陰陽、表裏、寒熱、虛實）、**衛氣營血辨證**（葉天士）、**三焦辨證**（吳鞠通）、清·程鍾齡《醫學心悟》之**八法**（汗吐下和溫清消補）——皆整理納入相關主題頁。
>
> 凡延伸材料皆以「**延伸**」提示框或加註與《內經》本體明確區別——以見《內經》→ 仲景 → 歷代之傳承理路，俾讀者本末了然，知何為《內經》本經之文、何為後世之發揮，臨證取用時自有分寸。

## 體系架構

每一主題自成一篇。**基礎物質**與**臟腑**兩類採固定**五區塊**：

<div class="grid cards" markdown>

-   :material-leaf: **一、生理**

    本主題在常態下的生成、運行與功能。

-   :material-fire: **二、病理**

    本主題的失常形態：虛實寒熱、出入升降。

-   :material-circle-multiple-outline: **三、臟象**

    與五臟、六腑、經絡（是動病・所生病）之對應。

-   :material-compass: **四、治則**

    依病態分立之治療大法。

-   :material-flask: **五、方藥**

    《神農本草經》代表藥物、《湯液經法》組方邏輯，並延伸仲景經方。

</div>

其餘類別依其性質另立結構：病因、病機、疾病、治則多以「概念 → 分類／機理 → 治則方藥」為骨幹；經絡按「循行 → 是動病 → 所生病」展開；診法按四診（望、聞問、切、辨證）分篇。

外部按主題分類，內部按層級展開——**橫看主題、縱看層級**。

## 凡例

- **底本**：王冰次註本《重廣補注黃帝內經素問》與《靈樞》
- **王冰注**：素問各篇原文逐句附王冰注（《靈樞》無王冰注）
- **方藥本體**：《**神農本草經**》（藥物氣味、三品、主治）
- **組方邏輯**：《**湯液經法**》（藉《輔行訣》復原）五味補瀉
- **延伸**：仲景經方、後世名方明確標記為「**延伸**」
- **引文**：純原文加註，不附白話翻譯
