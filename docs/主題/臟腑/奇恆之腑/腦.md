# 腦

## 一、生理

### （一）奇恆之腑

> 《素問·五臟別論》：「腦、髓、骨、脈、膽、女子胞，此六者，地氣之所生也，皆藏於陰而象於地，故藏而不瀉，名曰奇恆之府。」

腦為奇恆之腑——形態空腔似腑，功能藏精似臟。

### （二）主要功能

**髓海**——精所化髓上注於腦

> 《靈樞·海論》：「腦為髓之海。」

> 《素問·五臟生成》：「諸髓者，皆屬於腦。」

**主神志、為元神之府**

> 《素問·脈要精微論》：「頭者，精明之府，頭傾視深，精神將奪矣。」

明·李時珍《本草綱目·辛夷》：「**腦為元神之府**。」（後世發揮《內經》義）

要義：腦為精髓所聚，神明所居，主司精神、思維、記憶、感覺、運動。

### （三）腦與臟腑神志之關係

雖《素問·宣明五氣》「心藏神，肺藏魄，肝藏魂，脾藏意，腎藏志」明言**五神分藏五臟**——但《內經》亦多處暗示腦之神志功能：

> 《素問·脈要精微論》：「夫精明者，所以視萬物，別白黑，審短長⋯⋯」

> 《靈樞·海論》：「髓海有餘，則輕勁多力，自過其度；髓海不足，則腦轉耳鳴，脛痠眩冒，目無所見，懈怠安臥。」

故傳統說法為**心主神志、腦為神髓之所**——二者並重。

### （四）系統屬性

| 項目 | 對應 | 經典依據 |
|---|---|---|
| 屬類 | 奇恆之腑 | 《素問·五臟別論》 |
| 主藏 | 髓 | 《靈樞·海論》 |
| 主管 | 神明、感覺、運動 | 《素問·脈要精微論》 |
| 經絡聯繫 | **督脈**（貫脊上至腦）、**足太陽膀胱經**（從巔入絡腦） | 《素問·骨空論》、《靈樞·經脈》 |
| 化源 | 腎所藏之精 → 化髓 → 上注於腦 | 《靈樞·經脈》「精成而腦髓生」 |

## 二、病理

### （一）髓海不足（腦髓空虛）

> 《靈樞·海論》：「髓海不足，則腦轉耳鳴，脛痠眩冒，目無所見，懈怠安臥。」

主候：眩暈、耳鳴、健忘、思維遲鈍、發育遲緩、小兒囟門遲閉、老年痴呆——多由腎精虧虛所致。

### （二）瘀血阻腦

主候：頭痛固定、夜甚、舌紫黯、脈澀——多見於外傷或久病。

### （三）痰濁蒙蔽清竅

主候：頭暈頭重、神識昏蒙、嗜睡、舌苔厚膩、脈滑——痰濕上蒙清竅。

### （四）肝陽化風、腦病動風

主候：眩暈、抽搐、口眼歪斜、半身不遂、震顫——多見於中風、癲癇。

> 《素問·至真要大論》：「諸風掉眩，皆屬於肝。」

### （五）熱閉心包、邪犯腦竅

主候：高熱、神昏、譫語、抽搐——熱邪內陷、上犯腦髓。

### 病理總綱

> 《素問·脈要精微論》：「頭傾視深，精神將奪矣。」（腦病之危候）

## 三、臟象

### （一）與五臟之關係

- **腎**——腎藏精、生髓、上充於腦；**腦病多責於腎**
- **心**——心藏神，與腦同主神明；心腦同治為要
- **肝**——肝陽上亢、肝風內動、肝血不足皆可致腦病
- **脾**——脾化生氣血以濡養腦；脾虛痰生，痰濁蒙腦
- **肺**——肺朝百脈、助心行血，氣虛則腦失所養

### （二）相關之奇恆之腑

- **髓**——腦之物質基礎
- **骨**——骨之充亦源於髓

### （三）經絡聯繫

**督脈**——貫脊屬腎、上至腦
> 《素問·骨空論》：「督脈者⋯⋯與少陰直者，循脊裡，上至腦。」

**足太陽膀胱經**——從巔入絡腦
> 《靈樞·經脈》：「（膀胱經）從巔入絡腦，還出別下項。」

**手少陰心經**——支者上挾咽，繫目系，與腦相聯
**足厥陰肝經**——上出額，與督脈會於巔

故腦病常從調督脈、補腎、調肝、養心入手。

## 四、治則

| 病態 | 治則 |
|---|---|
| 髓海不足 | **補腎填精、益髓健腦** |
| 瘀血阻腦 | **活血化瘀、通絡** |
| 痰濁蒙竅 | **化痰開竅** |
| 肝風內動 | **平肝熄風、滋陰潛陽** |
| 熱閉腦竅 | **清熱開竅** |

兼顧原則：

- **腦腎同治**：補腎以填腦髓，是治腦病之本
- **心腦同治**：神明所主在心，腦為神髓所居，二者並重
- **氣血同調**：血養腦髓，氣行血行
- **辨虛實**：實者開竅、熄風、化痰；虛者填精、養血、補髓

### （二）方劑——以《湯液經法》五味補瀉解析

以**地黃飲子**（劉完素方，治瘖痱、髓海不足）為例：

- **組成**：熟地、巴戟天、山茱萸、肉蓯蓉、附子、官桂、石斛、麥門冬、五味子、茯苓、菖蒲、遠志、薄荷少許

- **湯液經法原則**（治腎兼治心）：
  > 「腎德在堅，以苦補之，甘瀉之；腎苦燥，急食辛以潤之。」

- **五味結構分析**：
    - **熟地、山茱萸、肉蓯蓉、巴戟天之甘酸**——填精補腎、養肝陰
    - **附子、官桂、菖蒲、遠志之辛**——溫陽通竅、潤腎之燥
    - **石斛、麥門冬之甘**——滋腎陰、養胃津
    - **五味子之酸**——收斂固澀
    - **薄荷之辛**——引藥上行至腦
    - 補腎陰陽、開竅啟閉並行——「**陰陽並補、開合並調**」之典範

## 註家集釋

- **王冰**注《素問·脈要精微論》「頭者，精明之府」：「頭高而上，故精神居之；目視萬物，故為精明之府。」
- **張介賓**《類經·藏象類》：「腦為髓之海⋯⋯凡骨之有髓，惟腦為主。」
- **張介賓**《類經·疾病類》：「五臟之精，皆上注於目；五臟六腑之精氣，皆上注於頭。」
- **李時珍**《本草綱目·辛夷》：「腦為元神之府。」（後世明確提出「元神」說）
- **王清任**《醫林改錯·腦髓說》：「靈機記性不在心而在腦。」（清末發揮）
