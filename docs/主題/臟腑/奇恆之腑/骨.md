# 骨

## 一、生理

### （一）奇恆之腑

> 《素問·五臟別論》：「腦、髓、骨、脈、膽、女子胞，此六者⋯⋯名曰奇恆之府。」

骨為奇恆之腑之一——具藏髓之功，故與單純之形體（如皮、肉）不同，列入奇恆。

### （二）主要功能

**支撐形體、保護臟腑**

> 《靈樞·經脈》：「人始生，先成精，精成而腦髓生，**骨為干**，脈為營，筋為剛，肉為牆，皮膚堅而毛髮長。」

**藏髓**——骨腔內充骨髓

**生齒之餘**——齒為骨之餘

> 《素問·上古天真論》：「腎氣盛，齒更髮長。」

### （三）系統屬性

| 項目 | 對應 | 經典依據 |
|---|---|---|
| 屬類 | 奇恆之腑 | 《素問·五臟別論》 |
| 主管臟 | 腎 | 《素問·痿論》「腎主身之骨髓」 |
| 五體歸屬 | 腎之合 | 《素問·宣明五氣》「腎主骨」 |
| 所充 | 髓 | 《靈樞·海論》 |
| 餘 | 齒（骨之餘） | 《素問·上古天真論》 |
| 經絡聯繫 | 足少陰腎經（貫脊屬腎）、督脈（貫脊） | 《靈樞·經脈》、《素問·骨空論》 |

## 二、病理

### （一）骨痿

主候：腰脊不舉、足不任身、骨節無力——多由腎熱、腎虛所致。

> 《素問·痿論》：「腎氣熱，則腰脊不舉，骨枯而髓減，發為骨痿。」

> 《素問·痿論》：「骨痿者，生於大熱也。」

### （二）骨蒸

主候：骨內蒸熱、午後潮熱、五心煩熱、盜汗、舌紅少津——陰虛火旺，熱自骨髓中蒸發。

### （三）骨痺

主候：骨節疼痛、屈伸不利、寒甚——寒濕侵骨。

> 《素問·痺論》：「**骨痺**不已，復感於邪，內舍於腎。」

> 《素問·長刺節論》：「病在骨，骨重不可舉，骨髓痠痛，寒氣至，名曰骨痺。」

### （四）骨折、骨損

外傷所致，治當接骨續筋。

### （五）齒搖髮脫

主候：牙齒鬆動、過早脫落、頭髮稀疏脫落——多由腎虛骨弱（齒為骨之餘）。

> 《素問·上古天真論》：「腎臟衰，形體皆極，則齒髮去。」

### 病理總綱

> 《素問·痿論》：「腎主身之骨髓⋯⋯腎氣熱，則腰脊不舉，骨枯而髓減，發為骨痿。」

## 三、臟象

### （一）與五臟之關係

- **腎**——主骨生髓；**骨病多責於腎**
- **肝**——主筋；筋骨並病者多兼肝（肝腎同源）
- **脾**——主肉、化生氣血；脾虛則肌肉不能榮筋骨

### （二）相關之奇恆之腑

- **髓**——骨之充
- **腦**——髓所聚之最上者

### （三）經絡聯繫

**足少陰腎經**——貫脊屬腎
**督脈**——貫脊上至腦
**足太陽膀胱經**——挾脊抵腰中

## 四、治則

| 病態 | 治則 |
|---|---|
| 骨痿 | **滋陰降火、補腎強骨** |
| 骨蒸 | **滋陰退蒸、清虛熱** |
| 骨痺 | **散寒除濕、溫經通絡、補腎強骨** |
| 骨折骨損 | **接骨續筋、活血化瘀** |
| 齒搖髮脫 | **補腎填精** |

兼顧原則：

- **腎為先**：補腎為治骨病之本
- **筋骨並調**：肝主筋、腎主骨，肝腎同治
- **氣血同調**：氣血充則骨得養
- **內外並重**：外傷骨損須內服外敷並施

### （二）方劑——以《湯液經法》五味補瀉解析

以**獨活寄生湯**（《備急千金要方》，治痺痛日久肝腎兩虧）為例：

- **組成**：獨活、桑寄生、杜仲、牛膝、細辛、秦艽、茯苓、桂心、防風、芎藭、人參、甘草、當歸、芍藥、地黃

- **湯液經法原則**（治腎兼治肝）：
  > 「腎德在堅，以苦補之，甘瀉之；腎苦燥，急食辛以潤之。」

- **五味結構分析**：
    - **獨活、秦艽、防風、細辛之辛**——祛風散寒除濕（潤腎之燥、發越伏邪）
    - **桑寄生、杜仲、牛膝之苦**——補肝腎、強筋骨（**苦補腎**）
    - **地黃、人參、甘草、茯苓之甘**——補氣養血、培土榮木
    - **芍藥之酸**——柔肝斂陰
    - **桂心、芎藭、當歸之辛**——溫通血脈、活血養血
    - 標本兼治、扶正祛邪——**「補腎強骨、祛風除濕、養血通絡」**之全面調理
