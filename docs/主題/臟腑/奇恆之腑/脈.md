# 脈

## 一、生理

### （一）奇恆之腑

> 《素問·五臟別論》：「腦、髓、骨、脈、膽、女子胞，此六者⋯⋯名曰奇恆之府。」

脈為奇恆之腑——為氣血運行之**通道**，本身亦藏氣血而不瀉。

### （二）「脈」之多義

「脈」於《內經》中含義有三，須分辨：

| 含義 | 內容 | 經典依據 |
|---|---|---|
| **血脈**（脈管） | 氣血運行之通道，奇恆之腑之「脈」 | 《靈樞·經脈》「脈為營」 |
| **經脈**（經絡） | 氣血循行之經絡系統 | 《靈樞·經脈》全篇 |
| **脈象**（診脈） | 寸口脈搏所反映之臟腑狀態 | 《素問·脈要精微論》 |

本頁主要討論**第一義**——作為奇恆之腑的「血脈」。

### （三）主要功能

**運行氣血**——氣血循脈而行，環周不休

> 《素問·脈要精微論》：「夫脈者，血之府也。」

> 《靈樞·脈度》：「氣之不得無行也，如水之流，如日月之行不休。故陰脈榮其臟，陽脈榮其腑，如環之無端。」

**約束氣血**——使其不溢出脈外

> 《素問·脈要精微論》：「夫脈者，血之府也。」（脈為血之居所）

### （四）系統屬性

| 項目 | 對應 | 經典依據 |
|---|---|---|
| 屬類 | 奇恆之腑 | 《素問·五臟別論》 |
| 主管臟 | 心（主血脈） | 《素問·痿論》「心主身之血脈」 |
| 助主之臟 | 肺（朝百脈）、脾（統血）、肝（藏血） | 《素問·經脈別論》、《難經·四十二難》 |
| 五體歸屬 | 心之合 | 《素問·六節藏象論》「心⋯⋯其充在血脈」 |

## 二、病理

### （一）脈虛

主候：脈細弱無力、面色淡白、心悸氣短——氣血不足，脈道空虛。

> 《靈樞·決氣》：「血脫者，色白，夭然不澤，**其脈空虛**，此其候也。」

### （二）脈瘀（血瘀阻脈）

主候：刺痛固定、舌紫黯、脈澀、肌膚甲錯、瘀斑——血行不暢，瘀阻脈絡。

> 《素問·調經論》：「孫絡水溢，則經有留血。」

### （三）脈寒（寒凝血脈）

主候：肢冷、痛、脈緊或沉遲——寒主收引，致脈道拘急。

> 《素問·調經論》：「血氣者，喜溫而惡寒，寒則泣不能流，溫則消而去之。」

### （四）脈熱（熱迫血脈）

主候：身熱、脈數、出血——熱邪迫血妄行。

### （五）脈痺（脈道閉阻）

> 《素問·痺論》：「**脈痺**不已，復感於邪，內舍於心。」

> 《素問·痺論》：「脈痺者，腰背節痛，痺氣循脈而行。」

主候：脈道閉阻、肢體麻木疼痛、脈澀或結代。

### （六）出血（脈道破損）

> 《靈樞·百病始生》：「陽絡傷則血外溢，血外溢則衄血；陰絡傷則血內溢，血內溢則後血。」

### 病理總綱

> 《素問·脈要精微論》：「夫脈者，血之府也，長則氣治⋯⋯短則氣病，數則煩心，大則病進⋯⋯。」（脈象反映病機）

## 三、臟象

### （一）與五臟之關係

- **心**——**主血脈**：脈之主導
  > 《素問·痿論》：「心主身之血脈。」
- **肺**——**朝百脈**：助心行血
  > 《素問·經脈別論》：「肺朝百脈，輸精於皮毛。」
- **脾**——**統血**：使血行於脈中而不外溢
  > 《難經·四十二難》：「脾⋯⋯主裹血。」
- **肝**——**藏血**：調節血量
  > 《素問·五臟生成》：「人臥則血歸於肝。」
- **腎**——藏精化血、為脈氣之根

### （二）相關之奇恆之腑

- **腦**——督脈通於腦，諸陽之會
- **女子胞**——衝任血海

### （三）經絡聯繫

血脈之循行依十二經絡之網絡，與奇經八脈相通。

**衝脈為十二經之海、血海**
> 《靈樞·海論》：「衝脈者，為十二經之海。」

## 四、治則

| 病態 | 治則 |
|---|---|
| 脈虛 | **補益氣血、養血和脈** |
| 脈瘀 | **活血化瘀、通脈** |
| 脈寒 | **溫經散寒、活血** |
| 脈熱 | **涼血清營** |
| 脈痺 | **溫通脈絡、活血祛邪** |
| 出血（脈傷） | **止血**（按寒熱虛實分清、溫、補、收） |

兼顧原則：

- **心為主**：脈病多責於心，治脈先調心
- **氣血同調**：氣為血帥，氣行則血行
- **溫通為要**：「血氣⋯⋯寒則泣不能流，溫則消而去之」
- **久病入絡**：久病之脈瘀宜搜剔通絡

### （二）方劑——以《湯液經法》五味補瀉解析

以**桂枝湯**（《傷寒論》調和營衛、和暢血脈之代表方）為例：

- **組成**：桂枝（辛）、白芍（酸）、生薑（辛）、大棗（甘）、炙甘草（甘）

- **湯液經法原則**（治脈兼治心肝肺）：
  > 「肝德在散，以辛補之，酸瀉之。」
  >
  > 「肺德在收，以酸補之，鹹瀉之。」（《輔行訣》引）

- **五味結構分析**：
    - **桂枝、生薑之辛**——溫通血脈、發散風寒（**辛補肝、辛瀉肺、通陽**）
    - **白芍之酸**——斂陰和營（**酸補肺、酸瀉肝**）
    - **甘草、大棗之甘**——緩急、調和諸藥
    - 辛、酸、甘三法並用，**「外調營衛、內和血脈」**——是中醫通脈名方
