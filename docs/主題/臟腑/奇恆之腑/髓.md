# 髓

## 一、生理

### （一）奇恆之腑

> 《素問·五臟別論》：「腦、髓、骨、脈、膽、女子胞，此六者⋯⋯名曰奇恆之府。」

### （二）髓之分類

依所充之部位，髓分為三：

- **腦髓**——上注於腦，主神明、感覺、運動之物質基礎
- **脊髓**——貫脊柱，連通腦與全身之氣血
- **骨髓**——充於骨腔，為骨之充

> 《素問·五臟生成》：「諸髓者，皆屬於腦。」（諸髓最終皆上注於腦）

### （三）化生與功能

**化生**：精所化

> 《靈樞·經脈》：「人始生，先成精，**精成而腦髓生**，骨為干，脈為營，筋為剛，肉為牆。」

> 《素問·陰陽應象大論》：「腎生骨髓。」

**功能**：

| 功能 | 內容 | 經典依據 |
|---|---|---|
| **充養腦** | 上注於腦，為神明之物質基礎 | 《靈樞·海論》「腦為髓之海」 |
| **養骨** | 充於骨腔，使骨堅固 | 《素問·痿論》「腎主身之骨髓」 |
| **化血** | 髓與血同源（後世「精血同源」之發揮） | 《素問·生氣通天論》 |
| **養筋脈** | 髓充則筋脈強健 | 《靈樞·經脈》 |

### （四）系統屬性

| 項目 | 對應 | 經典依據 |
|---|---|---|
| 屬類 | 奇恆之腑 | 《素問·五臟別論》 |
| 化源 | 腎所藏之精 | 《素問·陰陽應象大論》 |
| 所充 | 腦、骨、脊柱 | 《靈樞·海論》、《素問·痿論》 |
| 主管臟 | 腎 | 《素問·痿論》「腎主身之骨髓」 |

## 二、病理

### （一）髓海不足

主候：眩暈、耳鳴、健忘、思維遲鈍、發育遲緩——多由腎精虧虛。

> 《靈樞·海論》：「髓海不足，則腦轉耳鳴，脛痠眩冒，目無所見，懈怠安臥。」

### （二）骨髓空虛

主候：骨弱、腰膝痠軟、行動遲緩、骨質疏鬆——精虛不能化髓充骨。

> 《素問·痿論》：「腎氣熱，則腰脊不舉，骨枯而髓減，發為骨痿。」

### （三）髓痿（脊髓病變）

主候：四肢痿軟、屈伸不利、步履無力——多由精虧、熱毒或外傷。

### 病理總綱

> 《素問·脈要精微論》：「夫五臟者，身之強也⋯⋯腰者，腎之府，轉搖不能，腎將憊矣⋯⋯髓者，骨之充也，髓不滿則骨空，痿厥者生。」

---

## 三、臟象

### （一）與五臟之關係

- **腎**——腎藏精、生髓；**髓之化源在腎**
- **肝**——肝藏血、血養髓（精血同源）
- **脾**——脾化生氣血以資補髓
- **心**——心藏神、與腦髓並主神明

### （二）相關之奇恆之腑

- **腦**——髓海，為髓所聚之最上者
- **骨**——髓所充之處

### （三）經絡聯繫

**督脈**——貫脊上至腦，是脊髓之外應
> 《素問·骨空論》：「督脈者⋯⋯與少陰直者，循脊裡，上至腦。」

**足少陰腎經**——貫脊屬腎
**足太陽膀胱經**——挾脊抵腰中

---

## 四、治則

| 病態 | 治則 |
|---|---|
| 髓海不足 | **補腎填髓** |
| 骨髓空虛 | **補腎強骨**（以血肉有情之品） |
| 髓痿 | **滋陰補腎、強筋壯骨** |

兼顧原則：

- **補髓必補腎**：腎為生髓之源
- **填髓宜厚味**：血肉有情之品（鹿角膠、龜板膠、阿膠）多入髓海
- **氣血並調**：氣血充則髓有所養

### （二）方劑——以《湯液經法》五味補瀉解析

以**龜鹿二仙膠**（明·王肯堂《證治準繩》，填精補髓之代表方）為例：

- **組成**：鹿角（甘鹹溫）、龜板（鹹甘寒）、人參（甘）、枸杞子（甘）

- **湯液經法原則**（治腎填髓）：
  > 「腎德在堅，以苦補之，甘瀉之。」
  >
  > 「腎苦燥，急食辛以潤之。」

- **五味結構分析**：
    - **鹿角之甘鹹溫**——溫補陽氣、強筋健骨（補督脈、命門火）
    - **龜板之鹹甘寒**——滋陰潛陽、補腎健骨（補任脈、腎陰）
    - **人參之甘**——大補元氣、化生陰陽
    - **枸杞之甘**——補精血、養肝腎
    - **陰陽並補、血肉有情**——是補髓填精之至劑

此方體現「**血肉有情之品**」之治療大法——草木難達之深處（髓海、骨腔），須借動物精血之品方能直入。
