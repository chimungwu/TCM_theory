# 脾

## 一、生理

### （一）五行屬性

> 《素問·六節藏象論》：「脾胃大腸小腸三焦膀胱者，倉廩之本，營之居也⋯⋯其華在唇四白，其充在肌，其味甘，其色黃，此至陰之類，通於土氣。」

> 《素問·陰陽應象大論》：「中央生濕，濕生土，土生甘，甘生脾，脾生肉，肉生肺⋯⋯在臟為脾，在色為黃，在音為宮，在聲為歌，在變動為噦，在竅為口，在味為甘，在志為思。」

要義：脾屬土，**至陰之類**，主中州，通於長夏（或寄旺於四季之末十八日），**為氣血生化之源、後天之本**。

### （二）主要功能

**主運化**——運化水穀、運化水濕

> 《素問·經脈別論》：「飲入於胃，遊溢精氣，上輸於脾，脾氣散精，上歸於肺，通調水道⋯⋯」

> 《素問·厥論》：「脾主為胃行其津液者也。」

**主統血**——統攝血液於脈中

> 《難經·四十二難》：「脾⋯⋯主裹血，溫五臟。」

**主升清**——將水穀精微上輸心肺，並維持臟腑位置

> 《素問·陰陽應象大論》：「清氣在下，則生飧泄；濁氣在上，則生䐜脹。」

### （四）後天之本、氣血生化之源

> 《素問·靈蘭秘典》：「脾胃者，倉廩之官，五味出焉。」

> 《靈樞·五味》：「胃者，五臟六腑之海也，水穀皆入於胃，五臟六腑皆稟氣於胃。」

要義：脾與胃合稱「中焦」「中州」，化生氣血以養全身，故為**後天之本**；先天之精賴後天之精以充養，故脾胃失調最易生百病。

## 二、病理

### （一）脾氣虛

主候：食少、腹脹、便溏、神疲乏力、面色萎黃、舌淡、脈虛——脾失健運之常見證。

### （二）脾陽虛

主候：脘腹冷痛、喜溫喜按、食少便溏、四肢不溫、舌淡胖苔白滑——脾氣虛之進階。

### （三）中氣下陷

主候：脫肛、子宮下垂、久泄久痢、胃下垂——脾氣不升、清陽不展之變。

### （四）脾不統血

主候：便血、肌衄、月經過多、崩漏——脾氣虛弱、不能攝血。

> 《靈樞·百病始生》：「陰絡傷則血內溢。」

### （五）寒濕困脾

主候：脘腹脹悶、頭重身困、不思飲食、口黏不渴、便溏、舌苔白膩——濕邪困中、陽氣受遏。

> 《素問·至真要大論》：「諸濕腫滿，皆屬於脾。」

### （六）濕熱蘊脾

主候：脘悶嘔惡、口苦口黏、身重發熱、面目身黃、便溏不爽、苔黃膩、脈濡數——多兼及肝膽。

### （七）脾陰虛

主候：食少、口乾唇紅、舌紅少津、手足煩熱、大便乾結——較少獨見，多與胃陰虛並論。

### 病理總綱

> 《素問·至真要大論》：「諸濕腫滿，皆屬於脾。」
>
> 《素問·太陰陽明論》：「脾病而四肢不用何也⋯⋯今脾病不能為胃行其津液，四肢不得稟水穀氣，氣日以衰，脈道不利，筋骨肌肉，皆無氣以生，故不用焉。」

## 三、臟象

### （一）表裡之腑

**胃**（與脾相表裡）—— 水穀之海、五臟六腑之海

> 《素問·靈蘭秘典》：「脾胃者，倉廩之官，五味出焉。」

> 《素問·太陰陽明論》：「脾與胃以膜相連耳⋯⋯太陰陽明為表裡，脾胃脈也，生病而異者何也⋯⋯陽道實，陰道虛。」

要義：脾喜燥惡濕，胃喜潤惡燥；脾主升，胃主降。二者為氣機升降之樞軸。

### （二）系統相關之奇恆之腑

- **肌肉**——脾主之，賴脾運化之水穀精微濡養
- **四肢**——「四肢皆稟氣於胃，而不得至經，必因於脾，乃得稟也」（《素問·太陰陽明論》）
- **唇**——脾之外華
- **口**——脾之竅

### （三）經絡：足太陰脾經（《靈樞·經脈》）

**循行要點**：起於大趾之端，循趾內側白肉際，過核骨後，上內踝前廉，上腨內，循脛骨後，交出厥陰之前，上膝股內前廉，入腹屬脾，絡胃；上膈，挾咽，連舌本，散舌下。

**是動則病**：舌本強，食則嘔，胃脘痛，腹脹善噫，得後與氣，則快然如衰，身體皆重。

**是主脾所生病者**：舌本痛，體不能動搖，食不下，煩心，心下急痛，溏瘕泄，水閉，黃疸，不能臥，強立股膝內腫厥，足大指不用。

## 四、治則

總綱：

> 《素問·藏氣法時論》：「脾苦濕，急食苦以燥之⋯⋯脾欲緩，急食甘以緩之，用苦瀉之，甘補之。」

| 病態 | 治則 |
|---|---|
| 脾氣虛 | **健脾益氣** |
| 脾陽虛 | **溫中健脾** |
| 中氣下陷 | **益氣升陷** |
| 脾不統血 | **益氣攝血** |
| 寒濕困脾 | **溫中化濕** |
| 濕熱蘊脾 | **清熱化濕** |
| 脾陰虛 | **養脾陰、生津** |

兼顧原則：

- **培土為本**：脾為後天之本，諸虛皆當顧脾胃
- **燥濕得宜**：脾喜燥惡濕，化濕勿過於辛燥傷陰；滋陰勿過於膩礙脾運
- **升降同調**：脾升胃降，治脾常配和胃
- **「**安穀則昌，絕穀則亡**」**：胃氣為本，治療當保胃氣
- **見肝之病，知肝傳脾，當先實脾**（《金匱要略》）

### （二）方劑——以《湯液經法》五味補瀉解析

以**理中湯**（《傷寒論》溫中健脾基本方）為例：

- **組成**：人參（甘）、白朮（苦甘）、乾薑（辛）、炙甘草（甘）

- **湯液經法原則**：
  > 「脾德在緩，以甘補之，辛瀉之。」
  >
  > 「脾苦濕，急食苦以燥之。」（《輔行訣》引）

- **五味結構分析**：
    - **人參、炙甘草、白朮之甘**——補脾、緩中、培土生氣
    - **白朮之苦**——燥脾濕（脾苦濕）
    - **乾薑之辛**——既「瀉脾」（理氣機）、亦溫中陽（治脾陽虛）
    - 補（甘）、燥（苦）、溫（辛）三法兼備，是**「以甘補脾、苦燥脾濕、辛溫脾陽」**之純粹方

對照**四君子湯**（純補脾氣方）：以人參、白朮、茯苓、甘草，**全甘為主、佐白朮一味之苦**——更純粹的「以甘補脾」邏輯。
