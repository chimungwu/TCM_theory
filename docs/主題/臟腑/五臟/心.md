# 心

## 一、生理

### （一）五行屬性

> 《素問·六節藏象論》：「心者，生之本，神之變也，其華在面，其充在血脈，為陽中之太陽，通於夏氣。」

> 《素問·陰陽應象大論》：「南方生熱，熱生火，火生苦，苦生心，心生血⋯⋯在臟為心，在色為赤，在音為徵，在聲為笑，在變動為憂，在竅為舌，在味為苦，在志為喜。」

要義：心屬火，通於夏氣，為陽中之太陽，**為一身之主**。

### （二）主要功能

**主血脈**——推動血液循行於脈中

> 《素問·痿論》：「心主身之血脈。」

> 《素問·五臟生成》：「諸血者，皆屬於心。」

**主神明**——主宰精神、意識、思維

> 《素問·靈蘭秘典》：「心者，君主之官也，神明出焉。」

> 《靈樞·邪客》：「心者，五臟六腑之大主也，精神之所舍也。」

> 《靈樞·本神》：「所以任物者謂之心。」

### （三）系統屬性

| 項目 | 對應 | 經典依據 |
|---|---|---|
| 五行 | 火 | 《素問·陰陽應象大論》 |
| 五季 | 夏 | 同上 |
| 五味 | 苦 | 《素問·宣明五氣》「苦入心」 |
| 五色 | 赤 | 《素問·陰陽應象大論》 |
| 五志 | 喜 | 同上 |
| 五液 | 汗 | 《素問·宣明五氣》「心為汗」 |
| 五體 | 脈 | 《素問·宣明五氣》「心主脈」 |
| 其華 | 面 | 《素問·六節藏象論》 |
| 開竅 | 舌 | 《素問·金匱真言論》「南方赤色，入通於心，開竅於耳⋯⋯藏精於心」（《靈樞》補：開竅於舌） |
| 所藏 | 神 | 《靈樞·本神》 |
| 所惡 | 熱 | 《素問·宣明五氣》 |

### （四）心包絡——代心受邪

> 《靈樞·邪客》：「心者，五臟六腑之大主也⋯⋯故諸邪之在於心者，皆在於心之包絡。」

心包絡為心之外衛，外邪之犯心者，先犯心包，是以臨床上「**邪入心包**」實多指心包之病。

## 二、病理

### （一）心氣虛

主候：心悸氣短、活動則甚、自汗、神疲、舌淡、脈虛。

### （二）心陽虛

主候：心悸怔忡、形寒肢冷、面色㿠白、舌淡胖、脈微弱——心氣虛之進階。

### （三）心陽暴脫

主候：突發大汗淋漓、四肢厥冷、神識淡漠、脈微欲絕——亡陽之危候。

### （四）心血虛

主候：心悸、失眠多夢、健忘、面色淡白、舌淡、脈細。

### （五）心陰虛

主候：心悸、心煩、失眠、五心煩熱、潮熱盜汗、舌紅少津、脈細數。

### （六）心火亢盛

主候：心煩、口舌生瘡、舌尖紅赤、小便短赤澀痛（心移熱於小腸）、不寐。

> 《素問·至真要大論》：「諸痛癢瘡，皆屬於心。」

### （七）痰蒙心竅 / 痰火擾心

主候：神識昏蒙、語無倫次、狂躁不安、舌苔黃膩、脈滑數——痰火閉竅之變。

### （八）心脈痺阻

主候：心胸憋悶、心痛徹背、痛引肩臂、舌紫黯或有瘀斑——血瘀、痰阻、寒凝、氣滯皆可致。

> 《靈樞·經脈》（手少陰心經是動則病）：「嗌乾，心痛，渴而欲飲，是為臂厥。」

### 病理總綱

> 《素問·至真要大論》：「諸痛癢瘡，皆屬於心。」
>
> 《靈樞·本神》：「心怵惕思慮則傷神，神傷則恐懼自失。」

## 三、臟象

### （一）表裡之腑

**小腸**（與心相表裡）—— 受盛之官，泌別清濁

> 《素問·靈蘭秘典》：「小腸者，受盛之官，化物出焉。」

心經有熱可下移於小腸，見尿赤澀痛——**心移熱於小腸**之機。

### （二）系統相關之奇恆之腑

- **脈**——心主之，為氣血運行之道
- **舌**——心之竅，望舌可察心
- **面**——其華所在

### （三）經絡：手少陰心經（《靈樞·經脈》）

**循行要點**：起於心中，出屬心系，下膈絡小腸；其支者，從心系上挾咽，繫目系；其直者，復從心系卻上肺，下出腋下，循臑內後廉，行少陰、心主之後，下肘內，循臂內後廉，抵掌後銳骨之端，入掌內後廉，循小指之內，出其端。

**是動則病**：嗌乾，心痛，渴而欲飲，是為臂厥。

**是主心所生病者**：目黃，脅痛，臑臂內後廉痛厥，掌中熱痛。

### （四）手厥陰心包經（代心受邪）

**循行要點**：起於胸中，出屬心包絡，下膈，歷絡三焦⋯⋯

**是動則病**：手心熱，臂肘攣急，腋腫，甚則胸脅支滿，心中憺憺大動，面赤目黃，喜笑不休。

**是主脈所生病者**：煩心，心痛，掌中熱。

## 四、治則

總綱：

> 《素問·藏氣法時論》：「心苦緩，急食酸以收之⋯⋯心欲耎，急食鹹以耎之，用鹹補之，甘瀉之。」

| 病態 | 治則 |
|---|---|
| 心氣虛 | **補心氣** |
| 心陽虛 | **溫補心陽** |
| 心陽暴脫 | **回陽救逆** |
| 心血虛 | **養血安神** |
| 心陰虛 | **滋陰養心、清虛熱** |
| 心火亢盛 | **清心瀉火** |
| 痰蒙心竅 | **滌痰開竅** |
| 痰火擾心 | **清心滌痰** |
| 心脈痺阻 | **活血通脈、化痰宣痺、溫通散寒** |

兼顧原則：

- **心腎相交**：心火須下降溫腎，腎水須上濟養心。心陰虛、心火亢者多兼治腎
- **心脾同調**：心血賴脾化生，脾虛則心血亦虛
- **氣血同調**：心主血脈，氣為血帥，益氣以行血
- **凡刺之真，必先治神**（《素問·寶命全形論》）—— 治心病重在調神

### （二）方劑——以《湯液經法》五味補瀉解析

以**炙甘草湯**（復脈湯，治心動悸、脈結代）為例：

- **組成**：炙甘草（甘）、生薑（辛）、人參（甘）、生地黃（甘）、桂枝（辛）、阿膠（甘）、麥門冬（甘）、麻仁（甘）、大棗（甘）、清酒

- **湯液經法原則**：
  > 「心德在耎，以鹹補之，苦瀉之。」
  >
  > 「心苦緩，急食酸以收之。」（《輔行訣》引）

- **五味結構分析**：
    - **生地、阿膠、麥門冬之甘潤**——滋心陰、養心血以充養心體
    - **桂枝、生薑、清酒之辛**——通陽行血、振奮心氣以行其用
    - **炙甘草、人參、大棗、麻仁之甘**——緩急、補中、養心
    - 此方雖無顯著「鹹補」「苦瀉」「酸收」之三法，但**以滋陰養血為體、通陽復脈為用**，是「**陰陽並調、體用兼顧**」之臨床範例

## 註家集釋

- **王冰**注《素問·靈蘭秘典》「心者，君主之官也，神明出焉」：「任治於物，故為君主之官；清淨棲靈，故曰神明出焉。」
- **張介賓**《類經·藏象類》：「心為一身之君主，稟虛靈而含造化，具一理以應萬幾，臟腑百骸惟所是命，聰明智慧莫不由之。」
- **張志聰**《素問集註·六節藏象論》：「心為陽臟，居陽位，主血脈而藏神。」
