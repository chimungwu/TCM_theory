# 肺

## 一、生理

### （一）五行屬性

> 《素問·六節藏象論》：「肺者，氣之本，魄之處也，其華在毛，其充在皮，為陽中之太陰，通於秋氣。」

> 《素問·陰陽應象大論》：「西方生燥，燥生金，金生辛，辛生肺，肺生皮毛⋯⋯在臟為肺，在色為白，在音為商，在聲為哭，在變動為咳，在竅為鼻，在味為辛，在志為憂。」

要義：肺屬金，通於秋氣，**為陽中之太陰**（《素問》），居高位、為**華蓋**，**主一身之氣**。

### （二）主要功能

**主氣、司呼吸**——主一身之氣與呼吸之氣

> 《素問·六節藏象論》：「肺者，氣之本。」

> 《素問·陰陽應象大論》：「天氣通於肺。」

**主宣發肅降**——宣發布散、肅清下降

> 《素問·經脈別論》：「脈氣流經，經氣歸於肺，肺朝百脈，輸精於皮毛。」

**朝百脈、助心行血**——百脈之氣血皆朝會於肺，賴肺氣以推動

**通調水道**——為水之上源

> 《素問·經脈別論》：「飲入於胃⋯⋯上歸於肺，通調水道，下輸膀胱。」

### （四）肺為華蓋、為嬌臟

肺位居最高，覆蓋諸臟，故稱**華蓋**。其體清虛、其氣肅降、其性畏寒畏熱畏燥畏濕，**外邪易襲**且**自身易傷**，故謂**嬌臟**。

## 二、病理

### （一）肺氣虛

主候：氣短自汗、咳聲低微、易感外邪、面色㿠白、舌淡、脈虛——衛外不固之象。

### （二）肺陰虛

主候：乾咳少痰或痰中帶血、口乾咽燥、午後潮熱、五心煩熱、舌紅少津、脈細數。

### （三）風寒束肺

主候：咳嗽痰白稀、惡寒發熱、鼻塞流清涕、苔薄白、脈浮緊——風寒外襲之表證。

### （四）風熱犯肺

主候：咳嗽痰黃稠、發熱微惡風寒、咽痛、舌紅苔薄黃、脈浮數。

### （五）燥邪犯肺

主候：乾咳無痰或痰少而粘、咽乾鼻燥、口乾舌燥——分溫燥、涼燥。

### （六）痰濕阻肺

主候：咳嗽痰多色白易咯、胸悶、苔白膩、脈濡——多由脾虛生痰、上儲於肺。

### （七）痰熱壅肺

主候：咳喘痰黃稠、胸痛、發熱、舌紅苔黃膩、脈滑數——重則肺癰。

### （八）肺氣上逆

主候：咳嗽喘促——肺失肅降之總徵。

> 《素問·咳論》：「五臟六腑皆令人咳，非獨肺也。」

> 《素問·至真要大論》：「諸氣膹鬱，皆屬於肺。」

### 病理總綱

> 《素問·至真要大論》：「諸氣膹鬱，皆屬於肺；諸痿喘嘔，皆屬於上。」
>
> 《素問·咳論》：「皮毛者，肺之合也，皮毛先受邪氣，邪氣以從其合也。」

## 三、臟象

### （一）表裡之腑

**大腸**（與肺相表裡）—— 傳導之官

> 《素問·靈蘭秘典》：「大腸者，傳道之官，變化出焉。」

肺之肅降助大腸傳導，肺氣虛或肺燥皆可致大腸傳導失常（便秘、便溏）；反之，大腸實熱可上攻於肺。

### （二）系統相關之奇恆之腑與形體

- **皮毛**——肺主之，外邪由皮毛入肺
- **鼻**——肺之竅
- **喉嚨**——肺之門戶

### （三）經絡：手太陰肺經（《靈樞·經脈》）

**循行要點**：起於中焦，下絡大腸，還循胃口，上膈，屬肺，從肺系橫出腋下，下循臑內，行少陰、心主之前，下肘中，循臂內上骨下廉，入寸口，上魚，循魚際，出大指之端。

**是動則病**：肺脹滿，膨膨而喘咳，缺盆中痛，甚則交兩手而瞀，此為臂厥。

**是主肺所生病者**：咳，上氣，喘喝，煩心胸滿，臑臂內前廉痛厥，掌中熱。

## 四、治則

總綱：

> 《素問·藏氣法時論》：「肺苦氣上逆，急食苦以泄之⋯⋯肺欲收，急食酸以收之，用酸補之，辛瀉之。」

| 病態 | 治則 |
|---|---|
| 肺氣虛 | **補益肺氣** |
| 肺陰虛 | **養陰潤肺** |
| 風寒束肺 | **疏風散寒、宣肺止咳** |
| 風熱犯肺 | **疏風清熱、宣肺止咳** |
| 燥邪犯肺 | **潤肺生津**（溫燥涼潤、涼燥溫潤） |
| 痰濕阻肺 | **燥濕化痰** |
| 痰熱壅肺 | **清熱化痰** |
| 肺氣上逆 | **降氣止咳平喘** |

兼顧原則：

- **培土生金**：脾為肺之母，補脾以益肺
- **金水相生**：腎為肺之子，肺陰虛常兼補腎陰；腎虛不納氣者當補腎以納氣
- **肝肺氣機升降**：肺降肝升，治肝氣上逆喘咳當兼瀉肺氣
- **提壺揭蓋**：肺氣壅塞致下竅不利者，宣肺以通便、利尿
- **不可過汗**：嬌臟易傷，發汗解表須中病即止

### （二）方劑——以《湯液經法》五味補瀉解析

以**麻黃湯**（《傷寒論》辛溫解表方）為例：

- **組成**：麻黃（辛）、桂枝（辛）、杏仁（苦）、炙甘草（甘）

- **湯液經法原則**：
  > 「肺德在收，以酸補之，鹹瀉之。」
  >
  > 「肺苦氣上逆，急食苦以泄之。」（《輔行訣》引）

- **五味結構分析**：
    - **麻黃、桂枝之辛**——發越腠理，宣肺解表（**辛瀉肺**之過閉）
    - **杏仁之苦**——降肺氣、泄上逆（**苦泄肺氣**）
    - **炙甘草之甘**——緩中、調和諸藥
    - 此方以**「辛瀉」+「苦泄」並行**——既開腠理之閉、又降上逆之氣，正當風寒束肺之機

對照**桂枝湯**（解肌調營衛）：桂枝（辛）+ 白芍（酸）+ 炙甘草（甘）+ 生薑（辛）+ 大棗（甘）。其中**白芍之酸**正是「**酸補肺**」之收斂——使辛散有度、營衛調和。

## 註家集釋

- **王冰**注《素問·靈蘭秘典》「肺者，相傅之官，治節出焉」：「位高非君，故官為相傅；主行榮衛，故治節由之。」
- **張介賓**《類經·藏象類》：「肺者，臟之長也，為心之蓋，是經常多氣少血。」
- **張介賓**《類經·疾病類》：「肺體屬金，畏火者也，故熱則氣傷。」
- **張志聰**《素問集註·五臟生成》：「諸氣者，皆屬於肺；肺主通調水道。」
