# 胃

## 一、生理

### （一）腑之屬性

胃為六腑之一，與脾相表裡，同屬中焦，**為水穀之海、五臟六腑之海**。

> 《靈樞·五味》：「胃者，五臟六腑之海也，水穀皆入於胃，五臟六腑皆稟氣於胃。」

> 《素問·靈蘭秘典》：「脾胃者，倉廩之官，五味出焉。」

### （二）主要功能

**主受納、腐熟水穀**

> 《靈樞·玉版》：「胃者，水穀之海也。」

胃納食物，初步消化（腐熟），化為食糜，為脾運化之原料。

**主降濁**——胃氣以降為順

> 《素問·陰陽應象大論》：「濁氣在上，則生䐜脹。」

胃失和降則氣逆——嘔吐、噯氣、呃逆、腹脹皆胃氣不降之變。

### （三）系統屬性

| 項目 | 對應 | 經典依據 |
|---|---|---|
| 五行 | 土 | 與脾同屬 |
| 六氣 | 燥（陽明燥金） | 《素問·六微旨大論》（陽明燥土） |
| 表裡 | 與脾相表裡 | 《素問·太陰陽明論》 |
| 經絡 | 足陽明胃經 | 《靈樞·經脈》 |
| 別稱 | 倉廩之官、水穀之海、太倉 | 《素問·靈蘭秘典》 |

### （四）胃喜潤惡燥、脾喜燥惡濕

胃為陽腑，賴津液以潤；脾為陰臟，喜燥惡濕。**潤燥相濟**為脾胃調和之關鍵。

> 《素問·太陰陽明論》：「陽道實，陰道虛。」（胃陽常實、脾陰常虛之機）

### （五）「胃氣」之概念

> 《素問·平人氣象論》：「人以水穀為本，故人絕水穀則死，脈無胃氣亦死。」

> 《素問·玉機真藏論》：「五臟者，皆稟氣於胃；胃者，五臟之本也。」

「保胃氣」為治療之大法——脈得胃氣為生，失胃氣為死。

## 二、病理

### （一）胃寒

主候：胃脘冷痛、得溫則減、嘔吐清水、口淡不渴、舌淡苔白、脈遲——多由飲食生冷或寒邪直中。

### （二）胃熱（胃火熾盛）

主候：胃脘灼痛、消穀善飢、口臭、口渴喜冷飲、齒齦腫痛、便結尿黃、舌紅苔黃、脈滑數。

> 《素問·脈要精微論》：「胃脈⋯⋯實則脹，虛則泄。」

### （三）胃陰虛

主候：胃脘隱痛、嘈雜似飢而不欲食、口乾咽燥、大便乾結、舌紅少津、脈細數——熱病後期或久病傷陰。

### （四）胃氣虛

主候：胃脘隱痛、喜按、食少納呆、噯氣、神疲乏力——多兼脾氣虛。

### （五）胃氣上逆

主候：噁心嘔吐、噯氣、呃逆——胃失和降之總徵。

### （六）食滯胃脘

主候：脘腹脹滿疼痛、噯腐吞酸、惡聞食臭、嘔吐物為宿食、苔厚膩、脈滑——飲食停滯。

### （七）胃絡瘀阻

主候：胃脘刺痛、痛有定處、舌紫黯有瘀斑、脈澀——多見於久病。

### 病理總綱

> 《素問·五臟別論》：「水穀入口，則胃實而腸虛；食下，則腸實而胃虛。故曰實而不滿，滿而不實也。」

> 《素問·至真要大論》：「諸嘔吐酸，暴注下迫，皆屬於熱。」

## 三、臟象

### （一）表裡之臟

**脾**（與胃相表裡）—— 脾主升清、胃主降濁；脾喜燥惡濕、胃喜潤惡燥

> 《素問·太陰陽明論》：「脾與胃以膜相連耳⋯⋯太陰陽明為表裡，脾胃脈也。」

脾胃為氣機升降之樞軸——脾升則健，胃降則和。

### （二）「胃不和則臥不安」

> 《素問·逆調論》：「胃不和則臥不安。」

要義：胃氣不和可致心神不安、失眠——胃與神志相連，故安神常須和胃。

### （三）經絡：足陽明胃經（《靈樞·經脈》）

**循行要點**（多氣多血之經）：起於鼻之交頞中，旁納太陽之脈，下循鼻外，入上齒中，還出挾口環唇，下交承漿，卻循頤後下廉，出大迎，循頰車，上耳前，過客主人，循髮際，至額顱⋯⋯下乳內廉，下挾臍，入氣街中，下髀關，抵伏兔，下膝臏中，下循脛外廉，下足跗，入中指內間。

**是動則病**：洒洒振寒，善呻數欠，顏黑，病至則惡人與火，聞木聲則惕然而驚，心欲動，獨閉戶塞牖而處，甚則欲上高而歌，棄衣而走，賁響腹脹，是為骭厥。

**是主血所生病者**：狂、瘧、溫淫、汗出、鼽衄、口喎、唇胗、頸腫、喉痺、大腹水腫、膝臏腫痛，循膺、乳、氣街、股、伏兔、骭外廉、足跗上皆痛，中指不用。

## 四、治則

| 病態 | 治則 |
|---|---|
| 胃寒 | **溫胃散寒** |
| 胃熱 | **清胃瀉火** |
| 胃陰虛 | **養陰益胃** |
| 胃氣虛 | **益氣健胃**（多兼健脾） |
| 胃氣上逆 | **和胃降逆** |
| 食滯胃脘 | **消食導滯** |
| 胃絡瘀阻 | **活血化瘀** |

兼顧原則：

- **保胃氣存津液**為治療大法
- **脾胃同治**：脾胃為一升一降，治脾常配和胃，治胃常配健脾
- **降逆勿過於耗散**：胃氣本主降，降氣藥當中病即止，過用則傷胃陽
- **滋養勿過於滯膩**：胃喜潤但忌膩，滋陰宜輕清

### （二）方劑——以《湯液經法》五味補瀉解析

以**半夏瀉心湯**（和胃降逆、寒熱平調之代表方）為例：

- **組成**：半夏（辛）、乾薑（辛）、黃芩（苦）、黃連（苦）、人參（甘）、大棗（甘）、炙甘草（甘）

- **湯液經法原則**：
  > 「脾德在緩，以甘補之，辛瀉之。」（胃病同調脾）

- **五味結構分析**：
    - **半夏、乾薑之辛**——溫散寒結、降逆和胃（**辛瀉中焦之痞滿**）
    - **黃芩、黃連之苦**——清泄熱邪、燥濕降逆（**苦泄中焦之熱**）
    - **人參、大棗、炙甘草之甘**——補脾益胃、緩中補虛（**甘補中州**）
    - 辛開、苦降、甘補三法並用，正當**寒熱錯雜、虛實互見**之機

此方是「**辛開苦降甘補**」之典範——體現中焦痞滿之病機複雜，故組方亦複合三法。

## 註家集釋

- **王冰**注《素問·靈蘭秘典》「脾胃者，倉廩之官，五味出焉」：「包容五穀，是謂倉廩之官；榮養四傍，故云五味出焉。」
- **張介賓**《類經·藏象類》：「胃為水穀之海⋯⋯五臟六腑之大源也。」
- **張介賓**《景岳全書·脾胃》：「胃強脾弱，則陽有餘而陰不足，多為熱中善飢等證；脾強胃弱，則陰有餘而陽不足，多為飲食不易消化等證。」
- **張志聰**《素問集註·五臟別論》：「胃實則腸虛，腸實則胃虛，更虛更實，故氣得上下。」
