# 飲食勞逸

> 飲食失節、勞逸失度。內傷致病之常見因素。

## 一、飲食失節

> 《素問·痺論》：「**飲食自倍，腸胃乃傷**。」

> 《素問·上古天真論》：「**食飲有節，起居有常，不妄作勞，故能形與神俱**。」

### （一）飢飽失常

#### 過飢

主候：氣血生化之源不足、形體消瘦、神疲、抗病力弱。

**機理**：飲食不繼，氣血無源——後天之本失養。

#### 過飽

主候：脘腹脹滿、噯腐吞酸、大便不調、嘔吐宿食、食滯化熱。

**機理**：「飲食自倍，腸胃乃傷」——超過脾胃運化能力。

> 《素問·生氣通天論》：「**因而飽食，筋脈橫解，腸澼為痔**。」

### （二）飲食偏嗜

#### 五味偏嗜

> 《素問·宣明五氣》：「**五味所禁：辛走氣，氣病無多食辛；鹹走血，血病無多食鹹；苦走骨，骨病無多食苦；甘走肉，肉病無多食甘；酸走筋，筋病無多食酸**。」

> 《素問·五臟生成》：「**多食鹹，則脈凝泣而變色；多食苦，則皮槁而毛拔；多食辛，則筋急而爪枯；多食酸，則肉胝皺而唇揭；多食甘，則骨痛而髮落**。」

> 《素問·至真要大論》：「**夫五味入胃，各歸所喜⋯⋯酸先入肝，苦先入心，甘先入脾，辛先入肺，鹹先入腎，久而增氣，物化之常也。氣增而久，夭之由也**。」

要義：飲食五味各有所入；偏嗜某味則太過——其本所喜之臟反受傷。

#### 寒熱偏嗜

- **過食生冷**——傷脾陽，致脾胃虛寒、痰飲內生
- **過食辛熱**——傷胃陰，致胃熱、便秘、瘡瘍

#### 肥甘厚味偏嗜

主候：肥胖、痰濕、消渴、瘡瘍。

> 《素問·生氣通天論》：「**膏粱之變，足生大丁**。」（過食肥甘致疔瘡）

> 《素問·奇病論》：「**此肥美之所發也**⋯⋯**轉為消渴**。」（消渴病之飲食因）

#### 酗酒

主候：濕熱蘊結、肝胃損傷、血脈瘀阻——多致黃疸、酒癖、酒鼓。

### （三）飲食不潔

主候：腹痛、嘔吐、泄瀉、食物中毒、寄生蟲病。

> 《素問·至真要大論》：「⋯⋯食飲衣服，亦欲適寒溫。」

## 二、勞逸失度

> 《素問·宣明五氣》：「**久視傷血，久臥傷氣，久坐傷肉，久立傷骨，久行傷筋，是謂五勞所傷**。」

### （一）過勞

#### 1. 勞神（勞心）

主候：心悸、失眠、健忘、神疲、納呆——耗傷心血、脾氣。

> 《靈樞·本神》：「**心怵惕思慮則傷神**。」

#### 2. 勞力（過勞肢體）

主候：氣短、乏力、倦怠、汗多——耗氣傷形。

> 《素問·舉痛論》：「**勞則氣耗**⋯⋯勞則喘息汗出，外內皆越，故氣耗矣。」

#### 3. 房勞（房事過度）

主候：腰膝痠軟、精神萎靡、陽痿早泄、月經不調、不孕——耗傷腎精。

> 《素問·上古天真論》：「**以欲竭其精，以耗散其真**⋯⋯故半百而衰也。」

> 《靈樞·邪氣藏府病形》：「**入房汗出浴水，則傷腎**。」

### （二）過逸

主候：氣血不暢、脾胃功能減弱、肢體痿軟、肥胖、易感外邪。

> 《素問·宣明五氣》：「**久臥傷氣**。」

要義：**動則氣行**，過逸不動則氣血壅滯、生機減退。

## 三、總結治則

| 病機 | 治則 |
|---|---|
| **過飢致虛** | **補益氣血**（先和脾胃以受納） |
| **過飽傷食** | **消食導滯**（保和丸、枳實導滯丸） |
| **五味偏嗜** | **調飲食、平五味** |
| **肥甘致濕熱** | **化濕清熱**（兼食療調理） |
| **生冷傷陽** | **溫中健脾** |
| **辛熱傷陰** | **清熱養陰** |
| **酗酒致傷** | **解酒、清濕熱、護肝胃** |
| **食物中毒** | **解毒、和胃**（依毒物分治） |
| **勞神過度** | **養心安神、健脾** |
| **過勞傷氣** | **益氣補血** |
| **房勞傷腎** | **補腎填精** |
| **過逸氣滯** | **健脾運氣、適度勞動** |

### 治法要訣

- **節飲食、慎起居**：治本之道
- **過勞者勿過補**：先調脾胃以受補
- **房勞傷腎重在養**：節欲為本，藥補為輔
- **過逸宜動**：「動以養之」

## 五、經典出處彙集

> 《素問·上古天真論》：「食飲有節，起居有常，不妄作勞，故能形與神俱⋯⋯以欲竭其精，以耗散其真。」

> 《素問·痺論》：「飲食自倍，腸胃乃傷。」

> 《素問·生氣通天論》：「因而飽食，筋脈橫解，腸澼為痔⋯⋯膏粱之變，足生大丁。」

> 《素問·奇病論》：「此肥美之所發也⋯⋯轉為消渴。」

> 《素問·宣明五氣》：「久視傷血、久臥傷氣、久坐傷肉、久立傷骨、久行傷筋，是謂五勞所傷。」

> 《素問·舉痛論》：「勞則氣耗。」

> 《素問·五臟生成》：「多食鹹、苦、辛、酸、甘⋯⋯」（五味偏嗜致病）

## 註家集釋

- **王冰**注《素問·痺論》「飲食自倍，腸胃乃傷」：「言飲食適倍其常分，腸胃必傷之。」
- **張介賓**《類經·疾病類》：「**飲食所傷，多由失調**⋯⋯太過則傷腸胃，不及則傷氣血。」
- **李東垣**《脾胃論》（金·補土派代表）：「**內傷脾胃，百病由生**⋯⋯飲食勞倦皆傷脾胃。」
- **張志聰**《素問集註》：「五味以養五臟⋯⋯偏嗜則臟氣偏勝偏衰，皆能致病。」
