# 燥

> 傷津之邪。涼燥溫燥分二，最易傷肺。

## 一、性質與特點

> 《素問·陰陽應象大論》：「**燥勝則乾**。」

> 《素問·至真要大論》：「**諸澀枯涸，乾勁皴揭，皆屬於燥**。」（**註**：此為《內經》原文中無此十九條外之補述，後世劉完素於《素問玄機原病式》補入第二十條，故傳世版本各異。但**原十九條中無燥**，是病機十九條之缺。）

### 主要特點

| 特點 | 說明 |
|---|---|
| **乾澀** | 致皮膚乾燥、口鼻乾澀、舌乾、便結 |
| **傷津** | 直接耗傷津液 |
| **易傷肺** | 肺為嬌臟、喜潤惡燥，秋燥最易犯肺 |
| **時令性** | 主要發於秋季 |
| **分溫涼** | 初秋餘熱未盡為**溫燥**，深秋近寒為**涼燥** |

---

## 二、外燥

### （一）致病途徑

外燥由**口鼻、皮毛**侵入，先犯肺衛。多發於秋季。

### （二）溫燥

主候：身熱微惡風寒、頭痛、乾咳少痰或痰中帶血絲、咽乾口渴、舌紅苔薄黃、脈浮數。

**機理**：初秋餘熱兼燥邪犯肺。

**治則**：**辛涼甘潤、輕宣外燥**。

**代表方**：桑杏湯、清燥救肺湯。

### （三）涼燥

主候：發熱微惡風寒、頭痛無汗、乾咳少痰、咽乾鼻塞、舌淡苔薄白而乾、脈浮緊。

**機理**：深秋寒燥外侵、肺衛失宣。

**治則**：**輕宣涼燥、潤肺化痰**。

**代表方**：杏蘇散。

### 溫涼之辨

| 項目 | 溫燥 | 涼燥 |
|---|---|---|
| 季節 | 初秋（夏末初秋） | 深秋（秋末近冬） |
| 發熱惡寒 | 熱重寒輕 | 寒重熱輕 |
| 痰 | 少痰、可帶血 | 少痰，不帶血 |
| 舌苔 | 薄黃 | 薄白而乾 |
| 治法 | 辛涼甘潤 | 輕宣潤燥 |

---

## 三、內燥

### （一）形成

內燥多由**津液耗傷**所致：

- 熱病後期、傷津耗液
- 久病、汗吐下太過
- 失血、亡陰
- 年高體弱、津液不足

### （二）主要證候

| 部位 | 證候 |
|---|---|
| **上燥（傷肺）** | 乾咳少痰、咽乾鼻燥、聲音嘶啞 |
| **中燥（傷胃）** | 嘈雜、口乾、舌乾、便結 |
| **下燥（傷腎）** | 腰膝痠軟、形體消瘦、小便短少、便秘 |
| **血燥** | 皮膚乾枯、肌膚甲錯、瘙癢、髮枯 |
| **腸燥** | 大便秘結、糞如羊屎 |

### （三）治則

**滋陰潤燥**——按所傷之臟分治：

- 燥傷肺胃：滋陰潤肺、養胃生津（沙參麥冬湯、增液湯）
- 燥傷腎陰：滋補腎陰（六味地黃丸）
- 血燥：養血潤燥（四物湯加味）
- 腸燥便秘：潤腸通便（麻子仁丸、五仁丸、增液承氣湯）

---

## 四、總結治則

| 燥邪類型 | 治則 |
|---|---|
| 溫燥 | **辛涼甘潤** |
| 涼燥 | **輕宣潤燥** |
| 內燥（肺胃） | **滋陰潤肺養胃** |
| 內燥（腎） | **滋陰補腎** |
| 血燥 | **養血潤燥** |
| 腸燥 | **潤腸通便** |

### 治法要訣

- **燥者潤之**——治燥之根本
- **燥傷肺胃為主**——多取桑葉、杏仁、沙參、麥冬等
- **不可過於辛溫**——燥本傷津，過用辛溫反助燥
- **顧護胃津**——治燥過程中保胃津

## 五、經典出處彙集

> 《素問·陰陽應象大論》：「燥勝則乾。」

> 《素問·至真要大論》：「諸澀枯涸，乾勁皴揭，皆屬於燥。」（劉完素補入）

> 《素問·五運行大論》：「**燥以乾之**⋯⋯燥之化也。」

> 《素問·六元正紀大論》：「**燥勝則地乾**⋯⋯燥之復也，⋯⋯草乃晚生，咳嗌塞，胸脅滿引少腹。」

## 註家集釋

- **王冰**注《素問·陰陽應象大論》「燥勝則乾」：「燥者陽氣有餘，故為乾澀。」
- **劉完素**《素問玄機原病式·六氣為病》：「諸澀枯涸，乾勁皴揭，皆屬於燥。」（**補十九條之第二十**）
- **張介賓**《類經·疾病類》：「燥為金邪，其性收斂⋯⋯以其乾燥也。」
- **喻嘉言**《醫門法律·秋燥論》（清初發揮）：「秋傷於燥，上逆而咳，發為痿厥。」
- **吳鞠通**《溫病條辨·上焦篇》（清·溫病學）：「秋感燥氣，右脈數大，傷手太陰氣分者，桑杏湯主之。」
