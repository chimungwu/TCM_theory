# 痰飲瘀血

> 病理產物復為病因。痰飲為水液不歸正化、瘀血為血行不暢之積。

## 概說

「**痰飲**」「**瘀血**」本是病理產物——病在津液與血——但**形成之後復成新的致病因素**，攻擊本臟或他臟。

故中醫病因論將二者列為**內生病因**之主要類別，與外感、內傷三足鼎立。

---

## 一、痰飲

### （一）概念

**痰飲**——津液代謝失常，停聚於體內之病理產物。

> 《金匱要略》（後世總結《內經》義）：「**痰**之為物，隨氣升降，**遍身上下**，**無處不到**。」

### （二）有形與無形

| 類別 | 內容 | 表現 |
|---|---|---|
| **有形之痰** | 視之可見、觸之可及 | 咳吐之痰、皮下結塊（瘰癧、痰核）、嘔吐之痰水 |
| **無形之痰** | 視之不見、症之可徵 | 眩暈、悸動、神昏、癲狂、肢麻——「怪病多痰」 |

### （三）痰與飲之別

> 《金匱要略》區分四飲（後世發揮）：

| 名 | 部位 | 主候 |
|---|---|---|
| **痰飲** | 腸胃 | 腸鳴瀝瀝有聲、體瘦 |
| **懸飲** | 脅下 | 咳唾引痛 |
| **溢飲** | 四肢 | 身體疼重、肢腫 |
| **支飲** | 胸膈 | 喘咳氣急、不得平臥 |

一般而言：**稠濁者為痰，清稀者為飲**。

### （四）形成

> 《素問·至真要大論》：「**諸濕腫滿，皆屬於脾**。」

> 《素問·經脈別論》：「飲入於胃⋯⋯通調水道，下輸膀胱，水精四布，五經並行。」

水液代謝路徑：**胃 → 脾 → 肺 → 腎 → 膀胱**。任何環節失常皆可致水濕停聚化痰：

- **脾失運化**——濕聚成痰（**脾為生痰之源**）
- **肺失宣降**——津停化痰（**肺為儲痰之器**）
- **腎不化氣**——水泛為痰
- **三焦失司**——水道不利
- **肝失疏泄**——氣滯水停

> 後世李中梓：「脾為生痰之源，肺為貯痰之器。」

### （五）痰飲致病之特點

| 特點 | 表現 |
|---|---|
| **隨氣升降，無處不到** | 痰可見於頭、胸、腹、肢——故病候多端 |
| **病勢纏綿** | 痰飲為陰邪、性黏滯，病難速愈 |
| **影響氣血** | 痰阻氣機則氣滯、痰阻血脈則瘀阻、痰瘀互結 |
| **蒙蔽清竅** | 痰蒙心竅致神昏、痰擾心神致癲狂 |
| **怪病多痰** | 諸般難明之證，多責之於痰 |

### （六）主要證候

| 部位 | 主候 |
|---|---|
| **痰阻於肺** | 咳嗽痰多、喘促、胸滿 |
| **痰蒙心竅** | 神識昏糊、癲癇、痰鳴 |
| **痰擾心神** | 不寐、驚悸、狂躁 |
| **痰阻於胃** | 噁心嘔吐、脘痞、苔膩 |
| **痰阻經絡** | 肢麻、半身不遂、口眼歪斜、瘰癧、痰核 |
| **痰飲犯肺（咳喘）** | 哮喘痰鳴、不能平臥 |
| **眩暈** | 痰濁上蒙清陽 |

### （七）治則

**化痰**——按性質與部位分治：

| 痰性 | 治則 | 代表方 |
|---|---|---|
| 寒痰 | **溫化寒痰** | 苓甘五味薑辛湯、小青龍湯 |
| 熱痰 | **清熱化痰** | 清氣化痰丸、黃連溫膽湯 |
| 燥痰 | **潤燥化痰** | 貝母瓜蔞散 |
| 風痰 | **熄風化痰** | 半夏白朮天麻湯 |
| 濕痰 | **燥濕化痰** | 二陳湯 |
| 痰飲（水飲） | **溫陽化飲** | 苓桂朮甘湯、真武湯 |
| 痰熱擾神 | **清熱滌痰** | 礞石滾痰丸 |

### 治痰要訣

- **治痰先治氣**——氣行則津行
- **化痰必健脾**——絕生痰之源（脾為生痰之源）
- **久病多痰瘀互結**——化痰兼活血

## 二、瘀血

### （一）概念

**瘀血**——體內血液運行不暢、停滯於某處之病理狀態。包括：

- **離經之血**——血溢於脈外，不能消散
- **滯澀之血**——血在脈中而行不暢，停積為患

### （二）形成

> 《素問·繆刺論》：「人有所墮墜，**惡血留內**。」

> 《素問·調經論》：「**孫絡水溢，則經有留血**。」

#### 主要原因

| 原因 | 機理 |
|---|---|
| **氣滯** | 氣為血帥，氣滯則血瘀 |
| **氣虛** | 氣虛無力推血而瘀 |
| **血熱** | 熱迫血行，煎熬成瘀 |
| **血寒** | 寒凝血脈，泣不能流 |
| **外傷** | 跌仆損傷，血溢於外不能消散 |
| **久病** | 久病入絡，血行不暢 |

> 《素問·調經論》：「**血氣者，喜溫而惡寒，寒則泣不能流**。」

### （三）瘀血致病之特點

| 特點 | 表現 |
|---|---|
| **疼痛** | 刺痛、固定不移、夜甚、拒按 |
| **腫塊** | 體內可觸及包塊（癥）；或肌膚有青紫瘀斑（積） |
| **出血** | 反覆出血、色紫黯、夾血塊 |
| **色紫黯** | 舌紫黯、口唇紫、面色黧黑 |
| **肌膚甲錯** | 皮膚乾燥粗糙如鱗甲 |
| **脈澀** | 脈來艱澀不流利 |

### （四）主要證候

| 部位 | 主候 |
|---|---|
| **頭部瘀血** | 頭痛固定、夜甚、健忘 |
| **胸部瘀血** | 胸痛刺痛、固定、夜甚（如真心痛、胸痺重證） |
| **脅部瘀血** | 脅痛、脅下痞塊（肝脾腫大） |
| **腹部瘀血** | 腹痛拒按、癥瘕積聚 |
| **肢體瘀血** | 局部紫腫疼痛、脈管病 |
| **瘀血崩漏** | 經血色暗夾塊、痛經 |
| **產後惡露不下** | 少腹刺痛、惡露不暢 |

### （五）治則

**活血化瘀**——按程度分治：

| 程度 | 治則 | 代表方 |
|---|---|---|
| **輕** | **活血**（行氣活血） | 失笑散 |
| **中** | **化瘀**（活血通絡） | 桃紅四物湯、血府逐瘀湯 |
| **重** | **破血**（破血逐瘀） | 抵當湯、下瘀血湯 |

### 治瘀要訣

- **氣血同調**——氣行則血行，活血常配理氣（如血府逐瘀湯之柴胡、枳殼）
- **辨寒熱**——熱瘀者涼血、寒瘀者溫經
- **久病入絡**——蟲類藥（地龍、全蠍、水蛭）搜剔通絡
- **瘀血而虛**——攻補兼施

## 三、痰瘀互結

### 概念

痰與瘀同屬陰邪、同因氣機失常，**常相兼為病**。

> 後世發揮：「**痰瘀同源**」「**怪病多痰、頑病多瘀**」「久痰生瘀、久瘀生痰」。

### 主候

頑固性病候——半身不遂、癥瘕積聚、頑痺、心腦血管病、腫瘤、慢性肝炎硬化等多兼此機。

### 治則

**化痰祛瘀並施**——代表方：丹參飲、桃紅四物湯合二陳湯。

> 《素問·六元正紀大論》：「濕勝則濡泄，甚則水閉胕腫。」

> 《素問·繆刺論》：「人有所墮墜，惡血留內。」

> 《素問·調經論》：「孫絡水溢，則經有留血。」

> 《素問·調經論》：「血氣者，喜溫而惡寒，寒則泣不能流，溫則消而去之。」

> 《素問·百病始生》：「陽絡傷則血外溢，血外溢則衄血；陰絡傷則血內溢，血內溢則後血。」

## 註家集釋

### 痰飲

- **王冰**注《素問·至真要大論》「諸濕腫滿，皆屬於脾」：「脾主濕而惡濕。」
- **張介賓**《類經·疾病類》：「痰之化無不在脾，痰之本無不在腎⋯⋯不治痰而治氣，痰自消矣。」
- **李中梓**《醫宗必讀》：「**脾為生痰之源，肺為貯痰之器**。」（後世名言）
- **朱丹溪**《丹溪心法·痰》：「**怪病多屬痰**。」

### 瘀血

- **王冰**注《素問·繆刺論》「惡血留內」：「血凝結而不行，故為惡血。」
- **張介賓**《類經·疾病類》：「**血逆者氣亦逆，氣血和而後病不生**。」
- **王清任**《醫林改錯》（清末發揮）：「**治病之要訣，在明白氣血**⋯⋯氣有虛實，血有虛瘀。」
- **唐容川**《血證論》：「**離經之血為瘀血**。」
