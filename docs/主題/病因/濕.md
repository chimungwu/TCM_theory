# 濕

> 陰邪。重濁、黏滯、趨下、傷陽。「諸濕腫滿，皆屬於脾」。

## 一、性質與特點

> 《素問·至真要大論》：「**諸濕腫滿，皆屬於脾**。」

> 《素問·六元正紀大論》：「**濕勝則濡泄**。」

> 《素問·陰陽應象大論》：「**濕傷肉**⋯⋯**濕勝則濡泄**。」

### 主要特點

| 特點 | 說明 |
|---|---|
| **陰邪** | 性陰冷，易傷陽氣（尤傷脾陽） |
| **重濁** | 致頭重身困、肢體沉重；分泌物穢濁（如帶下穢濁、瘡瘍流膿） |
| **黏滯** | 致病勢纏綿、病程長、難速愈；分泌物黏膩 |
| **趨下** | 「傷於濕者，下先受之」（《素問·太陰陽明論》），故下肢、二陰、下焦多受 |
| **阻遏氣機** | 致胸悶脘痞、納呆、便溏 |
| **困脾** | 濕邪最易困脾，致運化失常 |

### 濕邪所致基本病機

> 《素問·太陰陽明論》：「**傷於濕者，下先受之**。」

---

## 二、外濕

### （一）致病途徑

外濕由**居處潮濕、淋雨涉水、汗出當風、長夏濕氣**所致。

### （二）主要證候

| 證型 | 主候 | 病機 |
|---|---|---|
| **濕困肌表（傷濕）** | 頭重如裹、身困肢倦、惡寒微熱、苔白膩 | 濕邪困表 |
| **濕痺（著痺）** | 關節重著疼痛、痛有定處、肌膚麻木 | 濕邪留滯關節 |
| **暑濕** | 身熱不揚、胸悶、噁心、便溏、苔白膩或黃膩 | 暑夾濕 |
| **寒濕** | 身重、惡寒、肢體痠痛、苔白膩、脈濡緩 | 寒夾濕 |
| **濕熱** | 身熱不揚、口苦、便溏不爽、苔黃膩、脈濡數 | 濕鬱化熱 |

### （三）治則

**化濕**——按所夾邪氣分治：

- 風濕：祛風勝濕（羌活勝濕湯）
- 寒濕：散寒化濕（藿香正氣散）
- 暑濕：清暑化濕（三仁湯、藿香正氣散）
- 濕熱：清熱化濕（甘露消毒丹、三仁湯）

---

## 三、內濕

### （一）形成

> 《素問·至真要大論》：「諸濕腫滿，皆屬於脾。」

內濕**根於脾陽不足**——脾失運化、水濕內停。

### （二）主要證候

| 部位 | 證候 |
|---|---|
| **濕困中焦** | 脘腹脹滿、納呆、噁心、便溏、苔白膩 |
| **濕注下焦** | 下肢浮腫、帶下、小便不利、淋濁 |
| **濕蒙清陽** | 頭重如裹、神識昏蒙 |
| **痰濕** | 咳痰、眩暈、肢體麻木 |
| **水濕泛溢** | 全身浮腫、體重 |

### （三）治則

**健脾化濕、利水滲濕**：

- 寒濕：溫中燥濕（平胃散、理中湯加味）
- 濕熱：清熱燥濕（茵陳蒿湯、龍膽瀉肝湯）
- 水濕泛溢：利水滲濕（五苓散、苓桂朮甘湯）
- 痰濕：化痰祛濕（二陳湯）
- 脾虛濕盛：健脾化濕（參苓白朮散、實脾飲）

---

## 四、濕邪轉化

### （一）寒化

濕遇寒從寒——形成**寒濕**。

### （二）熱化

濕遇熱從熱——形成**濕熱**。

> 《素問·六元正紀大論》：「濕勝則濡泄，甚則水閉胕腫。」

### （三）濕鬱化痰

濕邪久留、煉液成痰——濕痰互結。

---

## 五、總結治則

| 濕邪類型 | 治則 |
|---|---|
| 外濕（表） | **疏風祛濕** |
| 寒濕 | **散寒化濕** |
| 暑濕 | **清暑化濕** |
| 濕熱 | **清熱化濕** |
| 內濕（脾虛） | **健脾化濕** |
| 水濕泛溢 | **利水滲濕** |
| 痰濕 | **化痰祛濕** |

### 治法要訣

- **健脾為本**：脾為運化之樞，濕病之本
- **三焦分治**：上焦化濕宜輕宣（杏仁類）、中焦化濕宜苦溫（蒼朮、厚朴）、下焦化濕宜淡滲（茯苓、薏苡仁）
- **不可過於溫燥**：濕熱者忌大辛大熱，免化燥傷陰
- **不可過於滋潤**：濕邪未去而過於滋膩，反助濕

## 六、經典出處彙集

> 《素問·至真要大論》：「諸濕腫滿，皆屬於脾；諸痙項強，皆屬於濕。」

> 《素問·六元正紀大論》：「濕勝則濡泄，甚則水閉胕腫。」

> 《素問·陰陽應象大論》：「濕傷肉⋯⋯濕勝則濡泄。」

> 《素問·太陰陽明論》：「傷於濕者，下先受之。」

> 《素問·生氣通天論》：「**因於濕，首如裹**，濕熱不攘，大筋緛短，小筋弛長⋯⋯」

## 註家集釋

- **王冰**注《素問·至真要大論》「諸濕腫滿，皆屬於脾」：「脾主濕而惡濕，故諸濕病屬之。」
- **張介賓**《類經·疾病類》：「濕為土氣，其性重濁，故病多沉重而久留。」
- **張志聰**《素問集註》：「濕邪為患，最易困脾，亦最難速去。」
- **薛雪**《濕熱病篇》（後世）：「太陰內傷，濕飲停聚，客邪再至，內外相引，故病濕熱。」
