# 七情

> 喜、怒、憂、思、悲、恐、驚——七種情志。各傷其臟，「百病生於氣」之主因。

## 一、概念

### （一）七情與五志

**七情**——喜、怒、憂、思、悲、恐、驚

**五志**——喜、怒、憂（悲）、思、恐（驚）

七情屬人之常情，**過則成病**。常情不傷人，唯太過、不及、突然、持久者方傷臟腑氣血。

> 《素問·陰陽應象大論》：「**人有五臟化五氣，以生喜怒悲憂恐**。」

### （二）情志與臟腑之配屬

> 《素問·宣明五氣》：「**精氣并於心則喜，并於肺則悲，并於肝則憂，并於脾則畏，并於腎則恐**。」

> 《素問·陰陽應象大論》：「**怒傷肝**⋯⋯**喜傷心**⋯⋯**思傷脾**⋯⋯**憂傷肺**⋯⋯**恐傷腎**。」

| 情志 | 所主之臟 | 過則傷 |
|---|---|---|
| 喜 | 心 | 心氣渙散 |
| 怒 | 肝 | 肝氣上逆 |
| 憂 / 悲 | 肺 | 肺氣消耗 |
| 思 | 脾 | 脾氣鬱結 |
| 恐 / 驚 | 腎 | 腎氣下陷 / 散亂 |

---

## 二、七情致病之氣機變化

> 《素問·舉痛論》：「**百病生於氣也。怒則氣上，喜則氣緩，悲則氣消，恐則氣下，寒則氣收，炅則氣泄，驚則氣亂，勞則氣耗，思則氣結**。」

| 情志 | 氣機變化 | 主要病候 |
|---|---|---|
| **怒則氣上** | 氣血上逆 | 頭目脹痛、面紅目赤、嘔血、薄厥（中風前兆） |
| **喜則氣緩** | 心氣渙散 | 注意力不集中；甚則暴喜致心氣耗散、神不守舍 |
| **悲則氣消** | 上焦氣消 | 氣短、倦怠、咳喘、神疲 |
| **恐則氣下** | 氣陷於下 | 二便失禁、遺精、滑精；精神萎靡 |
| **驚則氣亂** | 氣機紊亂 | 心悸、驚怖、神不守舍、不寐 |
| **思則氣結** | 中焦氣結 | 食少、腹脹、鬱悶、脘痞 |
| **憂則氣聚** | 氣鬱不暢 | 胸悶、嘆息、抑鬱 |

---

## 三、七情致病之特點

### （一）直接傷及內臟

七情致病**不從外入**，而是直接擾亂臟腑氣機與氣血運行。

> 《素問·舉痛論》：「百病生於氣也⋯⋯」

### （二）影響氣機升降

七情致病主要表現為氣機升降出入之失常——詳見[升降出入失常](../病機/升降出入失常.md)。

### （三）多病不單一臟

雖各情各傷其臟，但因臟腑相關，常**多臟同病**：

- **肝**——情志致病之樞紐（怒、思、憂多兼肝鬱）
- **心**——情志致病之主宰（諸情志皆關心神）
- **脾**——情志致病之中州（思致脾鬱、肝鬱犯脾）

### （四）易致氣血津液失調

七情久傷可化生：

- **氣鬱** → 氣滯、痰鬱、火鬱
- **血瘀** → 氣滯而血行不暢
- **痰結** → 氣鬱而津液停聚
- **熱化** → 鬱久化火（五志過極皆從火化）

## 四、七情病機分述

### （一）怒——肝氣上逆

> 《素問·舉痛論》：「**怒則氣逆，甚則嘔血及飧泄，故氣上矣。**」

主候：頭痛眩暈、面紅目赤、急躁易怒、嘔血、女子月經失調、男子陽痿。

**極端**：**薄厥**——大怒致氣血並走於上、突然昏厥（多為中風發作）。

> 《素問·生氣通天論》：「**陽氣者，大怒則形氣絕，而血菀於上，使人薄厥**。」

### （二）喜——心氣渙散

> 《素問·舉痛論》：「**喜則氣和志達，營衛通利，故氣緩矣。**」

要義：適度之喜實為養生之常；唯**暴喜**或久喜不衰者方致病——「氣緩」過度而為散。

主候：精神不集中、心悸、語無倫次；甚則狂喜致心氣暴脫。

### （三）憂悲——肺氣消耗

> 《素問·舉痛論》：「**悲則心系急，肺布葉舉，而上焦不通，營衛不散，熱氣在中，故氣消矣**。」

主候：氣短乏力、咳喘、咽中梗塞感、聲音低微、神疲、嘆息。

### （四）思——脾氣鬱結

> 《素問·舉痛論》：「**思則心有所存，神有所歸，正氣留而不行，故氣結矣**。」

主候：食少納呆、脘腹脹滿、便溏、心悸失眠、健忘——脾不運化、心血不足。

> 《靈樞·本神》：「脾愁憂而不解則傷意，意傷則悗亂。」

### （五）恐——腎氣下陷

> 《素問·舉痛論》：「**恐則精卻，卻則上焦閉，閉則氣還，還則下焦脹，故氣不行矣**。」（亦作「恐則氣下」）

主候：二便失禁、遺精滑精、面色蒼白、心悸、骨痠軟。

> 《素問·脈要精微論》：「**得守者生，失守者死**。」

### （六）驚——氣機紊亂

> 《素問·舉痛論》：「**驚則心無所倚，神無所歸，慮無所定，故氣亂矣**。」

主候：心悸、神不守舍、不寐、易驚、神思恍惚。

## 五、五志過極化火

> 朱丹溪《格致餘論》（後世發揮）：「**五志之火，皆動於陽**⋯⋯**鬱火之類**。」

七情久鬱可化火——形成情志鬱火：

- 肝鬱化火：頭痛、目赤、口苦、急躁
- 心火亢盛：煩躁、不寐、口舌生瘡
- 鬱火傷陰：陰虛火旺、五心煩熱

## 六、治則總綱

| 病機 | 治則 |
|---|---|
| **氣機鬱滯** | **疏肝理氣**（柴胡、香附、鬱金） |
| **氣血上逆** | **平肝降逆**（牡蠣、龍骨、代赭石） |
| **心氣渙散** | **益氣斂神**（人參、五味子） |
| **氣陷於下** | **益氣升提**（黃耆、升麻、柴胡） |
| **思鬱傷脾** | **健脾解鬱**（歸脾湯、逍遙散） |
| **驚悸不寐** | **鎮驚安神**（朱砂、龍骨、牡蠣、酸棗仁） |
| **鬱久化火** | **疏肝瀉火**（丹梔逍遙散、龍膽瀉肝湯） |

### 情志之治法精要

> 《素問·陰陽應象大論》：「**怒傷肝，悲勝怒**；**喜傷心，恐勝喜**；**思傷脾，怒勝思**；**憂傷肺，喜勝憂**；**恐傷腎，思勝恐**。」

要義：**以情勝情**——五行相剋之理。一情過盛，可用其所克之情調之。

### 「移情易性」之法

非藥治者，亦為治法之一：

- 開導、啟發
- 移其志向、易其趣味
- 環境調適
- 運動以宣其鬱

## 註家集釋

- **王冰**注《素問·陰陽應象大論》「怒傷肝」：「肝主謀慮，怒甚則氣并於肝而傷之。」
- **張介賓**《類經·疾病類》：「凡五志之火，惟怒最暴⋯⋯故為害至大。」
- **張介賓**《類經·疾病類》：「**情志之傷，雖五臟各有所屬，然求其所由，則無不從心而發**。」
- **朱丹溪**《格致餘論·相火論》：「五志之火，皆動於陽。」
- **王清任**《醫林改錯》（後世）：「鬱怒傷肝，氣血逆亂，諸病乃生。」
