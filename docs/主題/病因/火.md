# 火

> 陽邪之極。實火虛火兼有，常動風動血。

## 一、火、熱、溫之關係

火、熱、溫**同類異名**，差別在於程度：

| 名 | 程度 | 病機特徵 |
|---|---|---|
| **溫** | 微熱（偏於溫和的熱邪） | 風溫、春溫等溫病 |
| **熱** | 中度熱 | 「諸熱瞀瘛，皆屬於火」之熱 |
| **火** | 熱之極 | 火性炎上、急驟、動風動血 |

> 《素問·陰陽應象大論》：「**壯火之氣衰，少火之氣壯。壯火食氣，氣食少火，壯火散氣，少火生氣**。」

要義：**少火**為生理之火（命門之火、心火、相火），**壯火**為病理之火。**少火生氣，壯火散氣**——同一物，狀態不同則生病迥異。

---

## 二、性質與特點

> 《素問·至真要大論》：「**諸熱瞀瘛，皆屬於火**⋯⋯**諸禁鼓慄，如喪神守，皆屬於火**⋯⋯**諸逆衝上，皆屬於火**⋯⋯**諸躁狂越，皆屬於火**⋯⋯**諸病胕腫，疼酸驚駭，皆屬於火**。」

### 主要特點

| 特點 | 說明 |
|---|---|
| **陽邪** | 性熱，故病多熱象 |
| **炎上** | 性向上，多致頭面、上焦病候 |
| **耗氣傷津** | 火熱蒸騰，最易傷氣傷津 |
| **動血** | 火熱迫血妄行——衄血、咯血、吐血、便血 |
| **動風** | 熱極生風——抽搐、神昏（諸熱瞀瘛） |
| **擾神** | 火擾心神——煩躁、狂越、不寐 |
| **生瘡瘍** | 火毒蘊結肌膚——癰、疽、疔、瘡 |

## 三、外火

### （一）來源

外火主要由**外感六淫之化熱**而來——風寒暑濕燥皆可化火：

> 後世發揮：「**六氣皆從火化**」（劉完素《素問玄機原病式》）

> 《素問·陰陽應象大論》：「**重寒則熱，重熱則寒**。」（陰陽極化之變）

### （二）主要證候

| 證型 | 主候 | 病機 |
|---|---|---|
| **氣分熱盛** | 大熱、大渴、大汗、脈洪大 | 邪入氣分（白虎湯證） |
| **熱入營血** | 身熱夜甚、神昏譫語、斑疹隱現、舌絳 | 邪熱深入營血 |
| **熱結腸腑** | 腹脹便秘、潮熱譫語、苔黃燥 | 燥屎內結、熱蒸於上 |
| **熱毒瘡瘍** | 紅腫熱痛、化膿 | 火毒蘊結肌肉 |

### （三）治則

- 衛分熱：辛涼透表（銀翹散、桑菊飲）
- 氣分熱：清氣熱（白虎湯）
- 營血熱：清營涼血（清營湯、犀角地黃湯）
- 腑實熱：通腑瀉熱（承氣類）
- 熱毒：清熱解毒（黃連解毒湯、五味消毒飲）

## 四、內火（內生五邪之一）

### （一）形成

內火多由**陰陽失調**所致：

- **陽盛則熱**——實火（壯火）
- **陰虛則熱**——虛火（陰虛之熱）
- **氣鬱化火**——肝氣鬱結、五志過極所化（如肝火、心火）
- **食積化火**——飲食停滯所化
- **濕鬱化火**——濕邪久留所化

### （二）實火與虛火之辨

| 項目 | 實火 | 虛火 |
|---|---|---|
| 起病 | 急 | 緩 |
| 熱型 | 壯熱、煩熱 | 午後潮熱、夜熱 |
| 渴 | 大渴喜冷飲 | 口乾不欲飲或喜熱飲 |
| 面 | 滿面通紅 | 兩顴泛紅 |
| 汗 | 多汗或無汗 | 盜汗 |
| 舌 | 舌紅苔黃厚 | 舌紅少苔或光剝 |
| 脈 | 洪數有力 | 細數無力 |
| 治 | 清熱瀉火 | 滋陰降火 |

### （三）五臟之火

| 火 | 主候 |
|---|---|
| **心火** | 心煩失眠、口舌生瘡、舌尖紅赤、小便赤澀 |
| **肝火** | 頭痛眩暈、目赤、口苦、易怒 |
| **胃火** | 消穀善飢、口臭、齒齦腫痛、便秘 |
| **肺火** | 咳嗽痰黃、咯血、咽痛 |
| **腎火**（虛火） | 五心煩熱、骨蒸潮熱、盜汗、夢遺 |

## 五、火邪變化

### （一）動風

> 《素問·至真要大論》：「諸熱瞀瘛，皆屬於火。」

熱極生風——高熱、抽搐、神昏。詳見[風](風.md)。

### （二）動血

火熱迫血妄行：

- 上溢：衄血、咯血、吐血
- 下溢：便血、尿血、崩漏
- 外溢：肌衄、瘀斑

### （三）擾神

火擾心神——煩躁、不寐、狂越。

> 《素問·至真要大論》：「諸躁狂越，皆屬於火。」

### （四）成毒

火熱壅聚化毒——癰疽瘡瘍。

## 六、總結治則

| 火邪類型 | 治則 |
|---|---|
| 實火 | **清熱瀉火**（按所在臟腑分治） |
| 虛火 | **滋陰降火** |
| 心火 | **清心瀉火**（黃連、梔子、燈心） |
| 肝火 | **清肝瀉火**（龍膽、夏枯草） |
| 胃火 | **清胃瀉火**（石膏、知母） |
| 肺火 | **清瀉肺熱**（黃芩、桑白皮） |
| 腎陰虛火 | **滋陰降火**（知柏地黃丸） |
| 動風 | **清熱熄風** |
| 動血 | **清熱涼血** |
| 火毒 | **清熱解毒** |

### 治法要訣

- **辨虛實**：實火用瀉、虛火用補（滋陰）
- **辨臟腑**：火有所屬，用藥各歸其經
- **「火鬱發之」**（《素問·六元正紀大論》）：鬱火宜散透
- **少火生氣，壯火散氣**：勿過於苦寒折真陽

## 七、經典出處彙集

> 《素問·陰陽應象大論》：「壯火之氣衰，少火之氣壯⋯⋯壯火散氣，少火生氣。」

> 《素問·至真要大論》：「諸熱瞀瘛、諸禁鼓慄、諸逆衝上、諸躁狂越、諸病胕腫，皆屬於火。」（病機十九條之火五條）

> 《素問·至真要大論》：「諸脹腹大、諸病有聲、諸轉反戾、諸嘔吐酸，皆屬於熱。」（病機十九條之熱四條）

> 《素問·六元正紀大論》：「**火鬱發之**。」

> 《素問·生氣通天論》：「**因於暑，汗，煩則喘喝**⋯⋯**因於氣，為腫，四維相代，陽氣乃竭**。」
