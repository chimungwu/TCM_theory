# 病因

> 病因者，致病之因也。中醫病因有外感、內傷、不內外因三大類。

---

## 病因之分類

### 外感病因

**六淫**——風、寒、暑、濕、燥、火六種外感邪氣

> 《素問·至真要大論》：「夫百病之生也，皆生於風寒暑濕燥火，以之化之變也。」

### 內傷病因

**七情**——喜、怒、憂、思、悲、恐、驚

**飲食勞逸**——飲食失節、勞逸失度

### 不內外因（內生病因）

**痰飲瘀血**——病理產物復為病因

## 病因致病之共通機理

> 《素問·遺篇·刺法論》：「正氣存內，邪不可干。」
>
> 《素問·評熱病論》：「邪之所湊，其氣必虛。」

要義：**病因致病須以正氣不足為前提**。同樣致病因素，正氣強者不病、正氣弱者病。
