# 痿

> 《素問·痿論》。**肢體痿弱不用**之疾。「**治痿者獨取陽明**」。

## 一、概念

> 《素問·痿論》：「**五藏使人痿**⋯⋯**故肺熱葉焦，則皮毛虛弱急薄著，則生痿躄也**。」

「**痿**」者，**痿弱不用**——肢體痿廢而失用、不能行走（痿躄）。

---

## 二、五痿（《素問·痿論》）

每一臟之熱皆可致痿——故痿病分**五臟痿**。

| 五痿 | 所主之臟 | 主候 | 機理 |
|---|---|---|---|
| **皮痿** | 肺 | 肺鳴、皮毛虛弱、肢體萎弱不用 | 肺熱葉焦、津不布於皮毛 |
| **肉痿**（脾痿） | 脾 | 肌肉不仁、痿弱、肢體不能任地 | 脾熱、胃乾而口渴、肉痿 |
| **脈痿** | 心 | 脛縱不能任地（脛無力） | 心氣熱、下脈厥而上 |
| **筋痿** | 肝 | 筋膜乾、口苦、白淫（精液下泄） | 肝氣熱、膽汁泄則口苦 |
| **骨痿** | 腎 | 腰脊不舉、骨枯髓減、足不任身 | 腎氣熱、骨枯髓減 |

### 痿之根本：肺熱葉焦

> 《素問·痿論》：「**肺者藏之長也**⋯⋯**肺熱葉焦則皮毛虛弱急薄，著則生痿躄也**。」

要義：**肺主皮毛、為氣之主**——肺熱致氣血津液不能布散於四肢，**為痿病之總機**。

---

## 三、治痿獨取陽明

> 《素問·痿論》：「**論言治痿者獨取陽明，何也**⋯⋯**陽明者，五藏六府之海，主潤宗筋，宗筋主束骨而利機關也**⋯⋯**故陽明虛則宗筋縱，帶脈不引，故足痿不用也**。」

### 陽明何以重要

| 理由 | 說明 |
|---|---|
| **陽明為五臟六腑之海** | 水穀化生氣血之根本 |
| **陽明主潤宗筋** | 宗筋束骨利關節，賴陽明氣血濡養 |
| **陽明虛則宗筋縱** | 陽明虛弱則筋骨失養而痿 |

### 治法

> 《素問·痿論》：「**治之各補其滎而通其俞，調其虛實，和其逆順，筋脈骨肉，各以其時受月，則病已矣**。」

要義：**獨取陽明**——調補脾胃為治痿之核心，無論何痿皆從調陽明（脾胃）入手。

---

## 四、痿之病因

### （一）外感

肺熱、暑濕等熱邪傷肺。

### （二）內傷

| 內傷因素 | 機理 |
|---|---|
| **思想無窮** | 思慮傷脾、傷心 |
| **情志過度** | 五志過極化火 |
| **房勞太過** | 「**入房太甚**，宗筋弛縱」 |
| **久居濕地** | 濕熱浸淫 |
| **遠行勞倦** | 勞傷筋骨 |

> 《素問·痿論》：「**思想無窮，所願不得**⋯⋯**入房太甚**⋯⋯**有所遠行勞倦，逢大熱而渴**⋯⋯**有所失亡**⋯⋯**有漸於濕，以水為事**⋯⋯」

### （三）後世補：肝腎虧虛

肝腎陰虛、精血不足、筋骨失養——為痿病常見內因。

---

## 五、治則

### （一）總綱

| 病機 | 治則 |
|---|---|
| **肺熱葉焦** | **清熱潤肺** |
| **濕熱浸淫** | **清熱利濕** |
| **脾胃虛弱** | **益氣健脾、補後天**（治痿獨取陽明） |
| **肝腎虧虛** | **滋補肝腎、強筋健骨** |
| **氣血虧虛** | **益氣養血、扶正起痿** |
| **瘀阻脈絡** | **活血通絡** |

### （二）治痿要訣

- **獨取陽明**——治痿之根本
- **不可純補純瀉**——多須扶正祛邪並施
- **久病兼瘀**——配活血通絡
- **滋陰潤燥為輔**——肺熱葉焦及陰虛者
- **不可過於辛溫**——傷陰助熱
