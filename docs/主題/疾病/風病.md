# 風病

> 《素問·風論》。風為百病之長，所致之病多端。

## 一、概念

> 《素問·風論》：「**風者，百病之長也，至其變化，乃為他病也**。」

「**風病**」廣義指**所有由風邪所致之病**；狹義專指《素問·風論》所列之「中風、五臟風、胃風、首風、漏風、洩風」等。

風之為病——「**善行而數變**」，與其他諸邪並行可化為多種病候。

---

## 二、風病分類（《素問·風論》）

### （一）中風（外風）

> 《素問·風論》：「**風之傷人也，或為寒熱，或為熱中，或為寒中，或為癘風，或為偏枯，或為風也**⋯⋯」

註：**內經之「中風」**——指外感風邪所致之病；後世「中風」（卒中、半身不遂）為內風所致。

| 表現 | 機理 |
|---|---|
| **寒熱** | 風夾寒則寒、風夾熱則熱 |
| **熱中** | 風入裡化熱 |
| **寒中** | 風夾寒入裡 |
| **癘風（大風、麻風）** | 風邪久客、化為惡疾 |
| **偏枯** | 風邪傷半身（後世之中風後遺） |
| **風（風證）** | 各種風病之總稱 |

### （二）五臟風

每臟有其風——各有特定症候：

| 五臟風 | 主候 |
|---|---|
| **肺風** | 多汗惡風，色皏然白，時咳短氣，晝日則差，暮則甚 |
| **心風** | 多汗惡風，焦絕善怒嚇，赤色，病甚則言不可快，診在口 |
| **肝風** | 多汗惡風，善悲，色微蒼，嗌乾善怒，時憎女子 |
| **脾風** | 多汗惡風，身體怠墮，四肢不欲動，色薄微黃，不嗜食 |
| **腎風** | 多汗惡風，面龐然浮腫，腰脊痛不能正立，其色炲，隱曲不利 |

### （三）特殊風病

#### 1. 胃風

> 《素問·風論》：「胃風之狀，**頸多汗，惡風，食飲不下，鬲塞不通，腹善滿，失衣則䐜脹，食寒則泄**。」

#### 2. 首風

> 《素問·風論》：「首風之狀，**頭面多汗惡風，當先風一日則病甚，頭痛不可以出內**。」

#### 3. 漏風

> 《素問·風論》：「漏風之狀，**或多汗，常不可單衣，食則汗出，甚則身汗，喘息惡風，衣常濡，口乾善渴，不能勞事**。」

機理：飲酒中風所致（酒風）。

#### 4. 洩風（泄風）

> 《素問·風論》：「洩風之狀，**多汗，汗出洩衣上，口中乾上漬，其風不能勞事，身體盡痛則寒**。」

機理：腠理疏鬆、外風直入。

## 三、後世之中風

> 《靈樞·刺節真邪》：「**虛邪偏客於身半，其入深，內居榮衛，榮衛稍衰，則真氣去，邪氣獨留，發為偏枯**。」

「**偏枯**」即後世之**中風後遺、半身不遂**。

### 後世中風之分類

| 類型 | 主因 | 主候 |
|---|---|---|
| **真中風（外風）** | 外風直中經絡 | 突然口眼歪斜、半身不遂 |
| **類中風（內風）** | 肝陽化風、痰濕、氣虛、血虛 | 突然昏倒、半身不遂、神昏 |
| **中經絡** | 邪在經絡 | 半身不遂而神識清 |
| **中臟腑** | 邪入臟腑 | 神昏不語、危候 |

### 中風之閉脫

| 類型 | 主候 | 治則 |
|---|---|---|
| **閉證** | 牙關緊閉、握拳不開、二便不通、神昏 | 開閉啟閉（蘇合香丸、安宮牛黃丸） |
| **脫證** | 目合口開、手撒尿遺、氣息微弱 | 回陽固脫（參附湯、四逆湯） |

---

## 四、治則

### （一）外風之治

- 風寒：辛溫解表（麻黃湯、桂枝湯）
- 風熱：辛涼解表（銀翹散、桑菊飲）
- 風濕：祛風勝濕（羌活勝濕湯）

### （二）內風之治（後世發揮）

> 詳見[風（內風）](../病因/風.md#三內風)

- 肝陽化風：平肝熄風（鎮肝熄風湯、天麻鉤藤飲）
- 熱極生風：清熱熄風（羚角鉤藤湯）
- 陰虛動風：滋陰熄風（大定風珠）
- 血虛生風：養血熄風（當歸飲子）

### （三）中風後遺之治

- 氣虛血瘀：補氣活血（補陽還五湯）
- 痰熱腑實：清熱化痰（星蔞承氣湯）
- 風痰阻絡：化痰通絡（牽正散、解語丹）

> 《素問·生氣通天論》：「**故風者，百病之始也，清靜則肉腠閉拒，雖有大風苛毒，弗之能害**。」
