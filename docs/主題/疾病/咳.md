# 咳

> 《素問·咳論》。**「五臟六腑皆令人咳，非獨肺也」**。

## 一、概念

> 《素問·咳論》：「**黃帝問曰：肺之令人咳，何也？岐伯對曰：五臟六腑皆令人咳，非獨肺也**。」

要義：**咳之本在肺，而五臟六腑之病皆可使肺氣上逆而咳**——故咳病之治不可專拘於肺。

---

## 二、咳之病機

### （一）外感咳

> 《素問·咳論》：「**皮毛者，肺之合也，皮毛先受邪氣，邪氣以從其合也**。其寒飲食入胃，從肺脈上至於肺則肺寒，肺寒則外內合邪因而客之，則為肺咳。」

機理：

1. 外邪由皮毛犯肺
2. 寒飲食由胃上至肺

兩種途徑——皆致肺寒、肺氣上逆。

### （二）內傷咳——五臟咳之傳

> 《素問·咳論》：「五臟各以其時受病，**非其時，各傳以與之**。人與天地相參，故五臟各以治時感於寒則受病，微則為咳，甚者為泄為痛。」

要義：

- 春——肝先受邪，傳之於肺則為肝咳
- 夏——心先受邪，傳之於肺則為心咳
- 長夏——脾先受邪，傳之於肺則為脾咳
- 秋——肺自受邪，為肺咳
- 冬——腎先受邪，傳之於肺則為腎咳

---

## 三、五臟咳

> 《素問·咳論》（按主要症候）：

| 五臟咳 | 主候 |
|---|---|
| **肺咳** | 咳而喘息有音，甚則唾血 |
| **心咳** | 咳則心痛，喉中介介如梗狀，甚則咽腫喉痺 |
| **肝咳** | 咳則兩脅下痛，甚則不可以轉，轉則兩胠下滿 |
| **脾咳** | 咳則右脅下痛，陰陰引肩背，甚則不可以動，動則咳劇 |
| **腎咳** | 咳則腰背相引而痛，甚則咳涎 |

---

## 四、六腑咳（五臟咳久而傳腑）

> 《素問·咳論》：「**五臟之久咳，乃移於六腑**⋯⋯」

| 五臟咳 → 六腑咳 | 主候 |
|---|---|
| **肺咳 → 大腸咳** | 咳而遺失（咳時失矢） |
| **心咳 → 小腸咳** | 咳而失氣（咳時放屁） |
| **肝咳 → 膽咳** | 咳嘔膽汁 |
| **脾咳 → 胃咳** | 咳而嘔，嘔甚則長蟲出 |
| **腎咳 → 膀胱咳** | 咳而遺溺 |

### 久咳乃聚——三焦受之

> 《素問·咳論》：「久咳不已，則**三焦受之**，三焦咳狀，**咳而腹滿，不欲食飲**。此皆聚於胃，關於肺，使人多涕唾，而面浮腫氣逆也。」

要義：久咳之**最終病位在三焦**——「**聚於胃，關於肺**」是咳病之精義。

## 五、後世之咳分類（依病因）

| 類型 | 主候 | 治則 |
|---|---|---|
| **風寒咳** | 咳痰白稀、惡寒發熱、無汗、苔薄白 | 疏風散寒、宣肺止咳 |
| **風熱咳** | 咳痰黃稠、發熱微惡風、咽痛、苔薄黃 | 疏風清熱、宣肺止咳 |
| **燥邪咳** | 乾咳少痰或無痰、咽乾口燥 | 潤燥止咳 |
| **痰濕咳** | 咳痰多色白、胸悶、苔白膩 | 燥濕化痰 |
| **痰熱咳** | 咳痰黃稠難咯、面赤、苔黃膩 | 清熱化痰 |
| **肝火犯肺咳** | 咳時面紅、咽喉乾癢、痰中帶血 | 清肝瀉肺 |
| **肺陰虛咳** | 乾咳、痰少黏、咽乾、潮熱盜汗 | 滋陰潤肺 |
| **肺氣虛咳** | 咳聲低微、氣短、自汗、易感冒 | 補益肺氣 |
| **腎不納氣咳** | 咳喘日久、動則氣促、腰膝痠軟 | 補腎納氣 |

## 六、治則

### （一）總綱

> 《素問·咳論》：「**治臟者治其俞，治腑者治其合**⋯⋯**治肺者治其經**。」

要義：**辨在臟在腑——分臟治、分腑治、分經治**。

### （二）臨床治則

| 病機 | 治則 |
|---|---|
| 外感咳（風寒） | **辛溫散寒、宣肺止咳** |
| 外感咳（風熱） | **辛涼疏風、宣肺止咳** |
| 燥咳 | **潤燥止咳** |
| 痰濕咳 | **燥濕化痰** |
| 痰熱咳 | **清熱化痰** |
| 肝火犯肺 | **清肝瀉肺** |
| 肺陰虛 | **滋陰潤肺** |
| 肺氣虛 | **補益肺氣** |
| 腎虛咳喘 | **補腎納氣** |

> 《素問·咳論》（全篇——咳之分類、機理、傳變、治則）

> 《素問·至真要大論》：「**諸氣膹鬱，皆屬於肺**；**諸痿喘嘔，皆屬於上**。」

> 《素問·宣明五氣》：「**五氣所病：肺為咳**。」

> 《素問·經脈別論》：「**飲食飽甚，汗出於胃；驚而奪精，汗出於心；持重遠行，汗出於腎；疾走恐懼，汗出於肝；搖體勞苦，汗出於脾**。」（提示飲食勞逸亦致咳）
