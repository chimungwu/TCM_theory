# 厥

> 《素問·厥論》。**氣血逆亂、陰陽不相順接**之疾——以**手足厥冷或厥逆昏倒**為主。

## 一、概念

> 《素問·厥論》：「**陽氣衰於下則為寒厥，陰氣衰於下則為熱厥**。」

「**厥**」有二義：

- **手足厥冷**——四末逆冷
- **昏厥**——突然昏倒、不省人事

---

## 二、寒厥與熱厥

> 《素問·厥論》：「**陽氣衰於下則為寒厥；陰氣衰於下則為熱厥**。」

### （一）寒厥

主候：手足厥冷（足下尤甚）、面色蒼白、踡臥喜溫、脈沉遲。

機理：

> 《素問·厥論》：「**前陰者，宗筋之所聚**⋯⋯**此人者質壯，以秋冬奪於所用，下氣上爭不能復，精氣溢下，邪氣因從之而上**也。氣因於中，**陽氣衰，不能滲營其經絡**，陽氣日損，陰氣獨在，故手足為之寒也。」

要義：陽氣衰於下、不能溫四末。

### （二）熱厥

主候：手足發熱（手心尤甚）、煩躁、口渴、面紅、脈數。

機理：

> 《素問·厥論》：「**酒入於胃，則絡脈滿而經脈虛**⋯⋯**脾主為胃行其津液者也，陰氣虛則陽氣入，陽氣入則胃不和，胃不和則精氣竭，精氣竭則不營其四肢也**⋯⋯酒氣與穀氣相薄，熱盛於中，故熱遍於身，內熱而溺赤也。**夫酒氣盛而慓悍，腎氣有衰，陽氣獨勝**，故手足為之熱也。」

要義：陰氣衰於下、陽獨勝於內、外則四肢熱。

---

## 三、六經厥

> 《素問·厥論》：「**巨陽之厥，則腫首頭重，足不能行，發為眴仆**⋯⋯**陽明之厥，則癲疾欲走呼，腹滿不得臥，面赤而熱，妄見而妄言**⋯⋯」

| 六經厥 | 主候 |
|---|---|
| **太陽厥** | 腫首頭重、足不能行、眴僕 |
| **陽明厥** | 癲疾欲走呼、腹滿不得臥、面赤熱、妄見妄言 |
| **少陽厥** | 暴聾、頰腫而熱、脅痛、胻不可以運 |
| **太陰厥** | 腹滿䐜脹，後不利，不欲食，食則嘔，不得臥 |
| **少陰厥** | 口乾溺赤，腹滿心痛 |
| **厥陰厥** | 少腹腫痛，腹脹，涇溲不利，好臥屈膝，陰縮腫，胻內熱 |

---

## 四、屍厥

> 《素問·繆刺論》：「**邪客於手足少陰、太陰、足陽明之絡，此五絡皆會於耳中，上絡左角，五絡俱竭，令人身脈皆動，而形無知也，其狀若屍，或曰屍厥**。」

主候：突然昏倒、不省人事、形如屍。

機理：邪客五絡、氣血暴亂、神識失守。

---

## 五、薄厥

> 《素問·生氣通天論》：「**陽氣者，大怒則形氣絕，而血菀於上，使人薄厥**。」

主候：大怒之後突然昏厥、面赤、可有抽搐。

機理：大怒致氣血並走於上、清竅閉阻——後世之中風先兆或腦血管意外多屬此。

---

## 六、其他厥

| 厥型 | 主候 | 機理 |
|---|---|---|
| **氣厥** | 突然昏倒、四肢厥冷、突如其來 | 氣機逆亂、清竅閉阻 |
| **血厥** | 失血或氣血不暢致厥 | 失血脫氣或氣滯血瘀 |
| **痰厥** | 突然神昏、喉中痰鳴 | 痰閉清竅 |
| **食厥** | 暴食後突然厥逆 | 食滯胃脘、氣機壅閉 |
| **暑厥** | 夏月暑熱致暑熱厥脫 | 暑熱傷氣 |
| **臟厥**（《傷寒論》） | 久病臟氣衰絕 | 危重之候 |

---

## 七、治則

### （一）寒厥

**回陽救逆**——四逆湯、通脈四逆湯。

### （二）熱厥

**清熱開竅**——白虎湯、清營湯（內熱壅盛而外厥）。

> 「**熱深厥深**」——熱盛於內反致外厥，須清裡熱。

### （三）屍厥

**急救醒神**——通關散吹鼻、按壓人中；蘇合香丸、安宮牛黃丸。

### （四）薄厥（中風）

**平肝熄風、開閉**——按閉脫分治：
- 閉證：開閉啟閉
- 脫證：回陽固脫

### （五）其他厥

| 證 | 治則 |
|---|---|
| 氣厥（實） | 順氣降逆（蘇合香丸） |
| 氣厥（虛） | 益氣固脫（生脈散、四逆湯） |
| 血厥（虛） | 補氣養血（人參養榮湯） |
| 血厥（實） | 活血順氣（通瘀煎） |
| 痰厥 | 滌痰開竅（蘇合香丸、礞石滾痰丸） |
| 食厥 | 通腑導滯 |
| 暑厥 | 清暑益氣、開竅 |

## 註家集釋

- **王冰**注《素問·厥論》「陽氣衰於下則為寒厥」：「陽氣衰，故下為寒；下寒則氣不溫四末，故手足為寒。」
- **張介賓**《類經·疾病類》：「**厥者，逆氣之名也**⋯⋯氣有逆順，氣逆則為厥。」
- **張介賓**《景岳全書·厥逆》：「**氣血逆亂，陰陽不相順接**——皆名曰厥。」
- **張志聰**《素問集註》：「厥者，**陰陽偏勝偏衰之變**也，故有寒厥熱厥。」
