# 瘧

> 《素問·瘧論》《刺瘧》。**寒熱往來、定時發作**之疾。

## 一、概念

> 《素問·瘧論》：「**夫痎瘧皆生於風**⋯⋯**夫風之與瘧也，相似同類**⋯⋯」

瘧——以**寒戰、壯熱、汗出、定時發作**為特徵的疾病。

> 《素問·瘧論》：「**瘧之始發也，先起於毫毛，伸欠乃作，寒慄鼓頷，腰脊俱痛；寒去則內外皆熱，頭痛如破，渴欲冷飲。**」

---

## 二、瘧之分類（依病因）

### （一）風瘧

> 《素問·金匱真言論》：「**秋善病風瘧**。」

主候：先寒後熱、汗出。

### （二）寒瘧（《素問·瘧論》）

主候：先寒後熱、寒多熱少、無汗或汗少。

機理：寒氣先客於分肉之間。

### （三）溫瘧

> 《素問·瘧論》：「**溫瘧者，得之冬中於風寒**⋯⋯**先熱而後寒**。」

主候：先熱後寒、熱多寒少。

機理：冬感風寒、伏邪至夏發為溫瘧。

### （四）癉瘧（單熱無寒）

> 《素問·瘧論》：「**癉瘧者，肺素有熱⋯⋯邪氣內藏於心，外舍於分肉之間，令人消爍肌肉。**」

主候：但熱不寒、煩渴、身熱、消瘦。

機理：肺素有熱、復感邪氣。

### （五）瘧之分類概覽

| 類型 | 寒熱表現 | 病機 |
|---|---|---|
| **風瘧** | 先寒後熱 | 秋感風邪 |
| **寒瘧** | 先寒後熱、寒多 | 寒氣客分肉 |
| **溫瘧** | 先熱後寒 | 冬感風寒、伏發 |
| **癉瘧** | 但熱不寒 | 肺素有熱 |
| **濕瘧** | 寒熱身重肢倦 | 暑濕 |

---

## 三、發作機理

> 《素問·瘧論》：「**邪氣客於風府，循膂而下，衛氣一日一夜大會於風府**⋯⋯**故衛氣應乃作**。」

要義：邪氣與衛氣相搏；衛氣**一日一夜行於人身一周**——當衛氣與邪氣相遇之時，發作；相離之時，緩解——故定時發作。

### 發作時間遲早之變

> 《素問·瘧論》：「其氣之舍深，內薄於陰，陽氣獨發，陰邪內著，陰與陽爭不得出，是以間日而作也。」

- 一日一發：邪在淺處
- 間日一發：邪舍深、與衛氣相遇之時延後
- 數日一發：邪愈深

---

## 四、五臟瘧（《素問·刺瘧》）

| 五臟瘧 | 主候 |
|---|---|
| **肺瘧** | 心寒，寒甚熱，熱間善驚，如有所見者 |
| **心瘧** | 令人煩心甚，欲得清水，反寒多不甚熱 |
| **肝瘧** | 令人色蒼蒼然，太息，其狀若死者 |
| **脾瘧** | 令人寒，腹中痛，熱則腸中鳴，鳴已汗出 |
| **腎瘧** | 令人洒洒然，腰脊痛宛轉，大便難，目眴眴然，手足寒 |

### 六腑瘧

亦各有所主——胃瘧、膽瘧等，皆有其特定病候。

---

## 五、治則

> 《素問·瘧論》：「**夫瘧之未發也，陰未並陽，陽未並陰，因而調之，真氣得安，邪氣乃亡**⋯⋯**當此之時，可以治之**。」

### （一）發作期之治

- 寒重者：溫裡散寒
- 熱重者：清熱除瘧
- 寒熱並見：和解少陽

### （二）發作前之治

> 《素問·刺瘧》：「**瘧脈滿大急，刺背俞**⋯⋯**諸瘧而脈不見，刺十指間出血**。」

主張**未發前先治**——以截斷其勢。

### （三）虛人之瘧

正氣不足、邪戀不去——當扶正以驅邪。

## 六、代表方藥

!!! note "延伸"
    後世治瘧名方多出仲景及溫病學派，屬延伸內容。

| 證型 | 代表方 | 治則對應 |
|---|---|---|
| **少陽瘧（寒熱往來）** | 小柴胡湯 | 和解少陽 |
| **濕瘧** | 達原飲（吳又可《溫疫論》） | 開達膜原、辟穢化濁 |
| **溫瘧** | 白虎加桂枝湯 | 清熱兼祛邪 |
| **寒瘧** | 柴胡桂薑湯 | 溫散兼和解 |
| **癉瘧** | 白虎加桂枝湯、柴胡白虎湯 | 清熱透邪 |
| **久瘧、虛瘧** | 何人飲 | 補氣養血、截瘧 |
| **截瘧專方** | 截瘧七寶飲、青蒿（截瘧要藥） | 截瘧 |

### 青蒿：

《本經》原無，《別錄》補入；近世發現其有效成分**青蒿素**對瘧疾有特效——古今相印。

## 註家集釋

- **王冰**注《素問·瘧論》：「瘧者，由瘧氣之所作，**寒熱循經而發**。」
- **張介賓**《類經·疾病類》：「**瘧之為病，由邪氣與衛氣相薄**⋯⋯衛氣行則邪退，衛氣止則邪發。」
- **張志聰**《素問集註》：「瘧者，**陰陽相搏之病也**⋯⋯陽勝則熱，陰勝則寒。」
- **吳又可**《溫疫論·瘧》（後世）：「**邪伏膜原**，發為瘧⋯⋯」
- **吳鞠通**《溫病條辨·下焦篇》：「**瘧母**，陳氣與痰飲混搏所致⋯⋯」（瘧母之發揮）
