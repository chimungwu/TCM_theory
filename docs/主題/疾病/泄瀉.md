# 泄瀉

> 《素問·太陰陽明論》《通評虛實論》。糞便溏稀、次數增多——脾失健運之變；久泄成腸澼。

## 一、概念

> 《素問·太陰陽明論》：「飲食不節，起居不時者，陰受之⋯⋯入五臟則䐜滿閉塞，下為飧泄，久為腸澼。」

「**泄瀉**」——大便溏稀或瀉下無度之症。《內經》依其形與勢別之為：

- **飧泄**——大便完穀不化、糞如殘渣
- **溏泄**——糞質稀薄、不成形
- **暴注**——瀉勢急猛、屬熱
- **腸澼**——久泄成滯下，便膿血、屬重證

---

## 二、泄瀉之病機

### （一）脾失健運（核心）

> 《素問·太陰陽明論》：「脾病而四肢不用⋯⋯今脾病不能為胃行其津液，四肢不得稟水穀氣⋯⋯」

脾主運化水穀精微。脾陽不足或脾為濕困，運化失司，清陽不升、水穀並下，是為泄瀉之本。

### （二）清氣在下

> 《素問·陰陽應象大論》：「清氣在下，則生飧泄。」

> 《素問·陰陽應象大論》：「春傷於風，夏生飧泄。」

清陽當升而反下，水穀混雜而走腸——飧泄之機。

### （三）寒熱之變

> 《素問·至真要大論》：「諸厥固泄，皆屬於下。」

> 《素問·至真要大論》：「諸暴注下迫，皆屬於熱。」

> 《素問·至真要大論》：「諸病水液，澄澈清冷，皆屬於寒。」

熱迫腸間則暴注下迫；寒入則澄澈清冷；下焦氣脫則固泄。

### （四）腸澼之機

> 《素問·太陰陽明論》：「久為腸澼。」

> 《素問·通評虛實論》：「腸澼便血⋯⋯」

久泄不止，腸絡受損，血溢腸中，乃成腸澼（後世稱痢疾、滯下）。

### （五）後世發揮

- **腎陽虛（命門火衰）**——五更泄
- **肝鬱乘脾**——情志致泄、痛瀉
- **食滯傷脾**——傷食泄

---

## 三、泄與腸澼之辨

| 病 | 性質 | 主候 |
|---|---|---|
| **飧泄** | 完穀不化 | 糞如殘渣、無膿血 |
| **溏泄** | 糞稀 | 黏溏、無膿血 |
| **暴注** | 急熱 | 瀉勢急猛、肛門灼熱 |
| **腸澼** | 滯下、便血 | 便膿血、裡急後重 |

---

## 四、辨證分型

| 證型 | 主候 | 機理 |
|---|---|---|
| **寒濕泄** | 瀉下清稀、腹痛喜溫、苔白膩、脈濡 | 寒濕困脾 |
| **濕熱泄** | 瀉下黃褐而臭、肛灼、苔黃膩、脈濡數 | 濕熱蘊腸 |
| **食滯泄** | 瀉下臭穢如敗卵、噯腐、腹脹 | 食積傷脾 |
| **脾虛泄** | 久泄不止、神疲、舌淡、脈弱 | 脾陽不足 |
| **腎虛泄（五更泄）** | 黎明腹瀉、形寒肢冷、舌淡胖 | 腎陽虛、命門火衰 |
| **肝鬱泄（痛瀉）** | 腹痛即瀉、瀉後痛減、與情志相關 | 肝鬱乘脾 |
| **腸澼（滯下）** | 便膿血、裡急後重、腹痛 | 濕熱久蘊、腸絡受損 |

---

## 五、治則

### （一）總綱

泄當辨**寒熱虛實**——

| 病機 | 治則 |
|---|---|
| 寒濕 | **散寒化濕** |
| 濕熱 | **清熱利濕** |
| 食滯 | **消食導滯** |
| 脾虛 | **健脾止瀉** |
| 腎虛 | **溫腎止瀉** |
| 肝鬱 | **抑肝扶脾** |
| 久泄 | **澀腸固脫** |
| 腸澼 | **清熱化濕、調氣行血** |

### （二）治泄要訣

- **辨升清降濁**——「清氣在下則生飧泄」，當升清為先
- **健脾為本**——脾健則濕去而泄自止
- **澀勿過早**——邪未盡而早澀，閉門留寇
- **腸澼當先除濕熱、調氣血**——非單純止瀉可解
