# 脹

> 《靈樞·脹論》。氣機壅滯、營衛留止所致之**胸腹脹滿**。專篇分五臟脹、六腑脹。

## 一、概念

> 《靈樞·脹論》：「夫脹者，皆在於藏府之外，排藏府而郭胸脇、脹皮膚，故命曰脹。」

「**脹**」——脹滿之病。其位在臟腑之外，撐張胸脇、脹及皮膚。脹以**氣**為主、無形可徵，按之或軟而不堅——與水腫之有水、積聚之有形者，性質不同。

---

## 二、脹之病機

脹之成，本於**衛氣逆亂、營衛留止**：

> 《靈樞·脹論》：「衛氣之在身也，常然並脈循分肉，行有逆順，陰陽相隨，乃得天和⋯⋯厥氣在下，營衛留止，寒氣逆上，真邪相攻，兩氣相搏，乃合為脹也。」

要義：衛氣行於分肉、本有常序；一旦厥逆之氣在下、寒氣逆上，營衛稽留、邪正相搏，氣壅而不行，乃成脹。

氣機升降失常亦致脹：

> 《素問·陰陽應象大論》：「濁氣在上，則生䐜脹。」

飲食起居失節，傷及脾胃，亦為內生之因：

> 《素問·太陰陽明論》：「飲食不節、起居不時者，陰受之⋯⋯入五臟則䐜滿閉塞。」

歸納病機：**寒滯、氣鬱、食積、脾虛、腑實**——皆使氣壅而為脹。

---

## 三、脹之分類

《靈樞·脹論》以臟腑為綱，分**五臟脹**與**六腑脹**。

### （一）五臟脹

> 《靈樞·脹論》：「心脹者，煩心短氣，臥不安。肺脹者，虛滿而喘咳。肝脹者，脇下滿而痛引小腹。脾脹者，善噦，四肢煩悗，體重不能勝衣，臥不安。腎脹者，腹滿引背央央然，腰髀痛。」

| 臟脹 | 主候 |
|---|---|
| **心脹** | 煩心、短氣、臥不安 |
| **肺脹** | 虛滿、喘咳 |
| **肝脹** | 脇下滿、痛引小腹 |
| **脾脹** | 善噦、四肢煩悗、體重、臥不安 |
| **腎脹** | 腹滿引背、腰髀痛 |

### （二）六腑脹

> 《靈樞·脹論》：「胃脹者，腹滿，胃脘痛，鼻聞焦臭，妨於食，大便難。大腸脹者，腸鳴而痛濯濯。小腸脹者，少腹䐜脹，引腰而痛。膀胱脹者，少腹滿而氣癃。三焦脹者，氣滿於皮膚中，輕輕然而不堅。膽脹者，脇下痛，口中苦，善太息。」

| 腑脹 | 主候 |
|---|---|
| **胃脹** | 腹滿、胃脘痛、妨於食、大便難 |
| **大腸脹** | 腸鳴而痛濯濯 |
| **小腸脹** | 少腹脹、引腰而痛 |
| **膀胱脹** | 少腹滿、氣癃（小便不利） |
| **三焦脹** | 氣滿於皮膚中、輕浮而不堅 |
| **膽脹** | 脇下痛、口苦、善太息 |

---

## 四、脹與相關病證之辨

| 病證 | 有無形質 | 按診 | 要點 |
|---|---|---|---|
| **脹** | 無形（氣） | 按之或軟、不必凹陷 | 氣壅胸腹 |
| **水腫** | 有水 | 按之凹陷 | 水溢肌膚（見 [水腫](水腫.md)） |
| **積聚** | 有形（積） | 觸之有塊 | 積有定處、聚無定形（見 [積聚](積聚.md)） |

---

## 五、治則

《靈樞·脹論》本以針治為主（「三里而寫，近者一下，遠者三下⋯⋯」）。本站經絡僅作生理，不展開針法，故治則以**法**為綱：

| 病機 | 治則 |
|---|---|
| 寒氣逆滿 | **溫中散寒、行氣** |
| 氣鬱壅滯 | **行氣寬中、消脹** |
| 食積中阻 | **消食導滯** |
| 脾虛失運 | **健脾運中、佐以行氣** |
| 腑實不通 | **通腑泄濁** |

要訣：脹以氣壅為本，**行氣**為通治之法；然須辨寒熱虛實——虛者忌純消、實者忌純補。
