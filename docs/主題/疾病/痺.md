# 痺

> 《素問·痺論》。**閉阻**之疾——氣血經絡為邪所閉。

## 一、概念

> 《素問·痺論》：「**黃帝問曰：痺之安生？岐伯對曰：風寒濕三氣雜至，合而為痺也**。」

「**痺**」者，**閉也**——氣血為風寒濕三氣所閉塞於經絡關節皮肉之間。

---

## 二、痺之分類

### （一）依邪氣偏勝分（**三痺**）

> 《素問·痺論》：「**其風氣勝者為行痺，寒氣勝者為痛痺，濕氣勝者為著痺也**。」

| 三痺 | 主候 | 病機 |
|---|---|---|
| **行痺**（風勝） | 肢節疼痛、遊走不定 | 風邪偏勝、善行數變 |
| **痛痺**（寒勝） | 肢節劇痛、痛有定處、得熱則減 | 寒邪偏勝、凝滯不行 |
| **著痺**（濕勝） | 肢體重著、肌膚麻木、酸楚不適 | 濕邪偏勝、重濁黏滯 |

### （二）熱痺（後世補入）

風寒濕痺久鬱化熱，或素體陽盛、感邪化熱：

主候：關節紅腫熱痛、發熱、口渴、苔黃。

> 後世發揮——《內經》原無「熱痺」之稱，但從病機十九條等可推。

### （三）依時令分（**五體痺**）

> 《素問·痺論》：「**以冬遇此者為骨痺，以春遇此者為筋痺，以夏遇此者為脈痺，以至陰遇此者為肌痺，以秋遇此者為皮痺**。」

| 五體痺 | 季節 | 主候 |
|---|---|---|
| **皮痺** | 秋 | 皮膚麻木、僵硬 |
| **肌痺** | 長夏 | 肌肉痠痛、感覺障礙 |
| **脈痺** | 夏 | 不仁、肌膚青紫、痛 |
| **筋痺** | 春 | 筋脈拘急、屈伸不利 |
| **骨痺** | 冬 | 骨節重痛、屈伸不便 |

### （四）五臟痺

> 《素問·痺論》：「**五臟皆有合，病久而不去者，內舍於其合也**⋯⋯**骨痺不已，復感於邪，內舍於腎；筋痺不已，復感於邪，內舍於肝；脈痺不已，復感於邪，內舍於心；肌痺不已，復感於邪，內舍於脾；皮痺不已，復感於邪，內舍於肺**。」

| 五體痺 → 五臟痺 | 主候 |
|---|---|
| **骨痺 → 腎痺** | 善脹，尻以代踵，脊以代頭 |
| **筋痺 → 肝痺** | 夜臥則驚，多飲，數小便，上為引如懷 |
| **脈痺 → 心痺** | 脈不通，煩則心下鼓暴上氣而喘，嗌乾善噫，厥氣上則恐 |
| **肌痺 → 脾痺** | 四肢解墮，發咳嘔汁，上為大塞 |
| **皮痺 → 肺痺** | 煩滿喘而嘔 |

### （五）六腑痺

> 《素問·痺論》：「**六腑亦各有俞，風寒濕氣中其俞，而食飲應之，循俞而入，各舍其腑也**。」

依此可推——胃痺、腸痺、膀胱痺等。

### （六）周痺

> 《靈樞·周痺》專論。

主候：邪客分肉之間、隨脈上下、痛無定處。

---

## 三、治則

> 《素問·痺論》：「**痺，其時有死者，或疼久者，或易已者，其故何也**⋯⋯**其入臟者死，其留連筋骨間者疼久，其留皮膚間者易已**。」

### （一）依邪氣分治

| 偏勝 | 治則 |
|---|---|
| **行痺**（風勝） | **祛風通絡**為主、養血為輔（治風先治血、血行風自滅） |
| **痛痺**（寒勝） | **溫經散寒、通絡止痛** |
| **著痺**（濕勝） | **祛濕通絡** |
| **熱痺** | **清熱通絡、祛風除濕** |

### （二）依病位分治

- **皮、肌痺**——多在表，宜祛邪透表
- **脈痺**——活血通絡
- **筋、骨痺**——深入難治，宜補益肝腎兼祛邪
- **臟痺**——已內舍於臟，治當扶正以驅邪、預後較差

### （三）依虛實分治

- 邪盛者祛邪
- 久病兼虛者攻補兼施

> 《素問·痺論》（全篇——痺之分類、傳變、治則）

> 《靈樞·周痺》（周痺、眾痺）

> 《素問·至真要大論》：「**諸暴強直，皆屬於風**；**諸寒收引，皆屬於腎**。」

> 《素問·痺論》：「**其風氣勝者為行痺，寒氣勝者為痛痺，濕氣勝者為著痺也**。」

> 《素問·痺論》：「**痛者，寒氣多也，有寒故痛也**。」

> 《素問·痺論》：「**痺在於骨則重，在於脈則血凝而不流，在於筋則屈不伸，在於肉則不仁，在於皮則寒**。」
