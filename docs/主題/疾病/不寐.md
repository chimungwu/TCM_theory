# 不寐

> 《靈樞·大惑論》《邪客》。目不能瞑、臥不能安——衛氣晝夜行止之失常。

## 一、概念

> 《靈樞·大惑論》：「衛氣不得入於陰，常留於陽。留於陽則陽氣滿，陽氣滿則陽蹻盛；不得入於陰則陰氣虛，故目不瞑矣。」

「**不寐**」——目不能瞑、臥不能安、寐不安寧之症。衛氣晝行於陽、夜入於陰乃為平人寐之常；不得入陰，則失寐。

> 《素問·逆調論》：「胃不和則臥不安。」

亦有起因於胃中食滯不化、胃氣不和而擾及心神者。

---

## 二、不寐之病機

### （一）衛氣不得入於陰（主因）

> 《靈樞·邪客》：「夫邪氣之客人也，或令人目不瞑、不臥出者，何氣使然？⋯⋯今厥氣客於五臟六腑，則衛氣獨衛其外，行於陽，不得入於陰；行於陽則陽氣盛，陽氣盛則陽蹻陷；不得入於陰，陰虛，故目不瞑。」

要義：邪氣或厥氣擾於臟腑，衛氣困守於陽而不能入陰，致陽盛陰虛、目不瞑——此即《內經》不寐之核心病機。

### （二）營衛失調、陰陽不交

> 《靈樞·營衛生會》：「夜半而陰隴為重陰⋯⋯」

夜為陰、衛當入陰；陰陽和則寐安，陰陽離決則失寐。

### （三）胃不和

> 《素問·逆調論》：「胃不和則臥不安。」

飲食不節、食滯中焦、胃氣不降、上擾心神——所謂「胃不和則臥不安」。

### （四）後世發揮之諸機

- **心血虛、心神失養**——虛則不榮
- **心火亢盛、痰熱內擾**——火、痰擾神
- **肝鬱化火、肝陽上擾**——情志失調
- **心腎不交**——水火不濟

---

## 三、辨證分型

| 證型 | 主候 | 機理 |
|---|---|---|
| **心脾兩虛** | 多夢易醒、心悸健忘、神疲倦怠、舌淡、脈細 | 心血脾氣兩虛、不能養神 |
| **陰虛火旺（心腎不交）** | 心煩失眠、五心煩熱、盜汗、舌紅少津、脈細數 | 腎陰虧虛、水不濟火 |
| **肝鬱化火** | 急躁易怒、目赤口苦、頭脹痛、舌紅苔黃、脈弦數 | 肝鬱化熱、上擾心神 |
| **痰熱擾神** | 心煩不寐、頭重目眩、胸悶、苔黃膩、脈滑數 | 痰熱壅滯、擾及心神 |
| **胃不和** | 脘腹脹滿、噯腐吞酸、夜臥不安、苔厚膩 | 食滯胃中、胃氣不降 |

## 四、治則

### （一）《內經》之治

> 《靈樞·邪客》：「治之奈何？⋯⋯飲以半夏湯一劑，陰陽已通，其臥立至。」

《內經》獨方——**半夏秫米湯**（半夏、秫米合煮），通陰陽，引衛入陰。為《內經》中極少數明列方劑之一。

### （二）依分型治

| 證型 | 治則 |
|---|---|
| **心脾兩虛** | 補益心脾、養血安神 |
| **陰虛火旺** | 滋陰降火、交通心腎 |
| **肝鬱化火** | 疏肝瀉火、安神 |
| **痰熱擾神** | 清熱化痰、和中安神 |
| **胃不和** | 和胃導滯 |
