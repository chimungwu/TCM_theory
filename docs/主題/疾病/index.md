# 疾病

> 《內經》中**有專篇所及**之具體病證。各篇按其病機、病候、治則自成體系。

---

## 本類目錄

### 外感類

<div class="grid cards" markdown>

-   :material-thermometer: **[熱病](熱病.md)**

    《素問·熱論》《刺熱》《評熱病論》。六經熱病傳變——「今夫熱病者，皆傷寒之類也」。

-   :material-shake: **[瘧](瘧.md)**

    《素問·瘧論》《刺瘧》。寒熱往來、定時發作。風瘧、寒瘧、溫瘧、癉瘧。

-   :material-weather-windy: **[風病](風病.md)**

    《素問·風論》。風為百病之長，分中風、五臟風、首風、漏風、洩風等。

</div>

### 肺系類

<div class="grid cards" markdown>

-   :material-air-filter: **[咳](咳.md)**

    《素問·咳論》。「**五臟六腑皆令人咳，非獨肺也**」——五臟咳、六腑咳。

</div>

### 痺痿厥類

<div class="grid cards" markdown>

-   :material-bone: **[痺](痺.md)**

    《素問·痺論》。行痺、痛痺、著痺；五體痺、五臟痺、六腑痺。

-   :material-human-handsdown: **[痿](痿.md)**

    《素問·痿論》。五痿（皮、肉、脈、筋、骨痿）；「**治痿獨取陽明**」。

-   :material-arrow-down-bold-circle: **[厥](厥.md)**

    《素問·厥論》。寒厥、熱厥；六經厥；尸厥、薄厥。

</div>

### 痛類

<div class="grid cards" markdown>

-   :material-emoticon-cry: **[痛](痛.md)**

    《素問·舉痛論》。十四痛之具體病機；「**寒氣多也，有寒故痛也**」。

</div>

### 內傷雜病類

<div class="grid cards" markdown>

-   :material-water: **[消渴](消渴.md)**

    《素問·奇病論》《氣厥論》。消癉、肺消、消渴、消中——津液耗傷之病。

-   :material-water-pump: **[水腫](水腫.md)**

    《素問·水熱穴論》《湯液醪醴論》。風水、皮水、正水、石水。「**腎者，胃之關也**」。

-   :material-rotate-3d-variant: **[眩暈](眩暈.md)**

    《素問》各篇。「**諸風掉眩，皆屬於肝**」「**髓海不足，則腦轉耳鳴**」。

-   :material-bag-personal: **[積聚](積聚.md)**

    《靈樞·百病始生》。癥瘕、積聚——有形之積。

-   :material-emoticon-confused: **[癲狂](癲狂.md)**

    《靈樞·癲狂》。「**重陰者癲，重陽者狂**」。

</div>

## 疾病分類之邏輯

《內經》之疾病分類**非以症狀為綱**，而以**病機為綱**：

```
外感類 ── 因六淫所致（熱病、瘧、風病）
   │
   ├─ 肺系類 ── 與肺直接相關（咳）
   │
   ├─ 痺痿厥類 ── 經絡氣血失常之三大門
   │
   ├─ 痛類 ── 各種疼痛之機理
   │
   └─ 內傷雜病類 ── 內傷七情、飲食勞逸所致
```
