# 診法

> 望、聞、問、切——察證之四法。《內經》論診，以「四診合參、先別陰陽」為綱。

---

## 診法在體系中之位置

診法承 [病機](../病機/index.md) 而起、啟 [治則](../治則/index.md)——
四診所得之證，經辨證歸屬於病性病位，方能依證立法。診法者，醫者與病情之間的橋樑。
