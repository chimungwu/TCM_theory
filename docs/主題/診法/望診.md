# 望診

> 望神、望色、望形態。以目察為診——「精明五色者，氣之華也」。

## 一、望神

神者，生命活動之外候。望神以斷生死順逆：

> 《素問·移精變氣論》：「得神者昌，失神者亡。」

得神（目光精彩、神識清明、反應靈敏）為佳；失神（目晦睛迷、神昏精敗）為危。神之所現，責於五臟精氣之盛衰。詳見 [神](../基礎物質/神.md)。

---

## 二、望色

### （一）色為氣之華

> 《素問·脈要精微論》：「夫精明五色者，氣之華也。」

面色為臟腑氣血之外榮，色之榮枯應臟腑之盛衰。

### （二）五色主病

五色分應五臟：

> 《素問·五藏生成》：「白當肺、辛，赤當心、苦，青當肝、酸，黃當脾、甘，黑當腎、鹹。」

| 五色 | 應臟 | 主病 |
|---|---|---|
| 青 | 肝 | 寒、痛、瘀、驚風 |
| 赤 | 心 | 熱 |
| 黃 | 脾 | 濕、虛 |
| 白 | 肺 | 虛、寒、失血 |
| 黑 | 腎 | 腎虛、寒、水飲、瘀 |

### （三）色之善惡

色貴明潤含蓄，忌晦暗暴露：

> 《素問·脈要精微論》：「赤欲如白裹朱，不欲如赭；白欲如鵝羽，不欲如鹽⋯⋯」

要義：五色當光明潤澤、隱然含蓄（如物之有所裹）；若枯槁暴露，則為臟氣衰敗之候。

---

## 三、望形態

望形體之強弱、姿態之動靜，以測正氣之盛衰、病位之所在。形盛者氣盛、形衰者氣衰——此即 [診法總論](診法總論.md) 所引「形之盛衰」並參之義。
