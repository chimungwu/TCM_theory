# 聞問診

> 聞聲嗅氣、問察病情。聞以耳鼻、問以言語。

## 一、聞診

### （一）聞五聲

五聲（呼、笑、歌、哭、呻）分應五臟：

> 《素問·陰陽應象大論》：「肝⋯⋯在音為角，在聲為呼⋯⋯心⋯⋯在音為徵，在聲為笑⋯⋯脾⋯⋯在音為宮，在聲為歌⋯⋯肺⋯⋯在音為商，在聲為哭⋯⋯腎⋯⋯在音為羽，在聲為呻。」

聲音之強弱、清濁，可測正氣盛衰與寒熱虛實——聲高有力多實，聲低氣怯多虛。

### （二）聞氣味

口氣、體氣，及二便排出物之氣味，亦為診病之資。氣味腐臭多屬實熱，氣味淡微多屬虛寒。

---

## 二、問診

### （一）問診之要

問診者，詢病之始末、起居飲食、苦樂所由。《內經》深戒不問而診：

> 《素問·徵四失論》：「診病不問其始，憂患飲食之失節，起居之過度，或傷於毒，不先言此，卒持寸口，何病能中。」

不問病因病史而徒持寸口，難中病情——此《內經》明示問診不可廢。

### （二）問之常法

> 《素問·疏五過論》：「凡欲診病者，必問飲食居處。」

問之內容，包括起病之因、病程之變、飲食、居處、二便、苦樂、舊疾——綜合以察病之所由與所在。
