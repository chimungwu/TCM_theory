# 總論

> 陰陽、五行——中醫說理之兩大框架。先於藏象氣血而立，為全書之理論基礎。

---

## 本類目錄

<div class="grid cards" markdown>

-   :material-yin-yang: **[陰陽](陰陽.md)**

    天地之道、萬物綱紀。對立、互根、消長、轉化——生理病理診治之總綱。

-   :material-pentagon-outline: **[五行](五行.md)**

    木火土金水之屬性與生剋。臟腑歸類、相互資生制約之機。

</div>

---

## 與其他類別之關係

陰陽五行為**說理之工具**，非具體之物，其應用貫穿全書——
[基礎物質](../基礎物質/氣.md) 之氣分陰陽、[臟腑](../臟腑/五臟/肝.md) 依五行歸類、[病機](../病機/陰陽失調.md) 以陰陽失調為綱、[治則](../治則/調整陰陽.md) 以調陰陽為本。
