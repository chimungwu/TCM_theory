# 病機

> 病機者，疾病發生、發展、變化之機理也。

《素問·至真要大論》：「謹守病機，各司其屬，有者求之，無者求之，盛者責之，虛者責之，必先五勝，疏其血氣，令其調達，而致和平，此之謂也。」

---

## 本類目錄

<div class="grid cards" markdown>

-   :material-scale-balance: **[邪正盛衰](邪正盛衰.md)**

    病機之核心。「邪氣盛則實，精氣奪則虛」——所有病機皆建立於邪正交爭之上。

-   :material-yin-yang: **[陰陽失調](陰陽失調.md)**

    陰陽偏盛、偏衰、互損、格拒、亡失。寒熱虛實之根本變化。

-   :material-arrow-up-down: **[升降出入失常](升降出入失常.md)**

    氣機升降出入為生命運行之根本。「出入廢則神機化滅，升降息則氣立孤危」。

-   :material-numeric-9-circle: **[病機十九條](病機十九條.md)**

    《素問·至真要大論》核心。五臟病機、上下病機、六氣病機之系統歸納。

-   :material-vector-link: **[病傳](病傳.md)**

    病之傳變——表裡傳、臟腑生剋傳、經絡傳。病勢之順逆。

</div>

## 病機之三層結構

```
邪正盛衰 ── 病機之總綱（虛實之根本）
   │
   ├─ 陰陽失調 ─── 病性之根本（寒熱虛實之變）
   │
   ├─ 升降出入失常 ─ 氣機之變（病位之動）
   │
   └─ 病機十九條 ─── 病性病位之具體歸屬
       │
       └─ 病傳 ──── 病勢之發展
```
