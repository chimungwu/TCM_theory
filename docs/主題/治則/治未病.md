# 治未病

> **聖人不治已病治未病。** 中醫預防醫學之核心思想。

## 一、概念

> 《素問·四氣調神大論》：「**是故聖人不治已病治未病，不治已亂治未亂，此之謂也。夫病已成而後藥之，亂已成而後治之，譬猶渴而穿井，鬪而鑄錐，不亦晚乎**。」

「治未病」非指治尚未發生之病，而是**在病之初萌、未顯、未變、未復之時**，先予防範與調治。

### 三大層次

```
未病先防 ── 病未起時，預防發病
既病防變 ── 病已起時，預防傳變
瘥後防復 ── 病已癒時，預防復發
```

---

## 二、未病先防

### （一）核心：扶正

> 《素問·遺篇·刺法論》：「**正氣存內，邪不可干**。」

預防之根本在於**強壯正氣**——使邪不能干。

#### 養正氣之法

| 法 | 經典依據 |
|---|---|
| **法於陰陽** | 《素問·上古天真論》「法於陰陽，和於術數」 |
| **食飲有節** | 《素問·上古天真論》 |
| **起居有常** | 《素問·上古天真論》 |
| **不妄作勞** | 《素問·上古天真論》 |
| **恬惔虛無** | 《素問·上古天真論》「恬惔虛無，真氣從之，精神內守，病安從來」 |
| **適時鍛鍊** | 後世導引、太極之養 |

### （二）避邪氣

> 《素問·上古天真論》：「**虛邪賊風，避之有時**。」

| 方面 | 內容 |
|---|---|
| **避六淫** | 順應四時，添減衣物，慎居處 |
| **避七情** | 心情舒暢，避免大悲大喜 |
| **避飲食** | 不食腐敗、不潔之物 |
| **避傳染** | 對傳染病避其疫氣（《素問·遺篇·刺法論》「**五疫之至，皆相染易**⋯⋯**正氣存內，邪不可干**，避其毒氣」） |

### （三）養生與藥食調補

> 《素問·上古天真論》：「**美其食，任其服，樂其俗**⋯⋯所以能年皆度百歲。」

當身體有所偏（如氣虛、陽虛、陰虛），平日可用食療、輕補劑調之，避免發展為大病。

例：

- 氣虛者——常服黃耆、紅棗
- 陽虛者——適度溫補（生薑、肉桂）
- 陰虛者——適度滋潤（百合、麥冬、銀耳）

## 三、既病防變

### （一）核心：早期診治

病已發生，當**及早診治、阻斷病勢**。

> 《素問·陰陽應象大論》：「**故邪風之至，疾如風雨，故善治者治皮毛，其次治肌膚，其次治筋脈，其次治六府，其次治五藏。治五藏者，半死半生也**。」

要義：**病在表淺易治，深入難治**。

### （二）防止傳變

#### 1. 阻斷外傳之路徑

外邪從表入裡——表邪不解則內傳。

例：感冒初起當解表，使邪從表出；若失治則邪入裡，化熱、化燥、化毒。

#### 2. 截斷臟腑生克傳變

> 《金匱要略》（後世發揮）：「**夫治未病者，見肝之病，知肝傳脾，當先實脾**。」

要義：**先安未受邪之地**——預先強化將要受傳之臟。

例：

- 見肝病知肝傳脾——先實脾
- 見心病知心傳肺（火克金）——先固肺
- 見腎病知腎傳心（水克火）——先養心

#### 3. 阻斷六經傳變

六經傳變（《素問·熱論》），當**截斷扭轉**：

- 太陽病不解則入陽明、少陽——當在太陽時即解之
- 三陽病不解則入三陰——當在三陽時即截之

#### 4. 阻斷氣血津液之失常進展

如：

- 氣鬱不解 → 化火、生痰、致瘀——應在氣鬱時即疏之
- 痰濕不化 → 痰瘀互結——應在濕痰時即化之

## 四、瘥後防復

### （一）核心：調復餘邪、扶元氣

病已癒而正氣尚未全復、餘邪未盡——當**調養以防復發**。

### （二）瘥後注意

#### 1. 食復

> 《素問·熱論》：「**病已愈，時有所遺者，何也⋯⋯諸遺者，熱甚而強食之，故有所遺也，若此者，皆病已衰而熱有所藏，因其穀氣相薄，兩熱相合，故有所遺也**。」

> 《素問·熱論》：「**病熱少愈，食肉則復，多食則遺，此其禁也**。」

要義：熱病後**慎飲食**——勿過食、勿食肉、勿食辛辣油膩。

#### 2. 勞復

過早勞動致正氣未復而病復發。

當靜養、適度活動。

#### 3. 房復

熱病後過早行房——傷腎致病復發。

#### 4. 七情之復

新癒之後情志波動易致復發。

### （三）瘥後調理

| 方面 | 法 |
|---|---|
| **調脾胃** | 參苓白朮散、理中湯（補後天） |
| **養氣血** | 八珍湯、十全大補湯 |
| **益肺固表** | 玉屏風散 |
| **滋陰補腎** | 六味地黃丸、左歸丸 |
| **適度活動** | 散步、太極、八段錦 |

## 五、治未病之具體應用

### （一）不時之預防

| 時段 | 預防重點 |
|---|---|
| **春季** | 預防風病、肝病、流行性感冒 |
| **夏季** | 預防中暑、暑濕、心病 |
| **長夏** | 預防濕病、脾胃病 |
| **秋季** | 預防燥病、肺病、瘧 |
| **冬季** | 預防寒病、心腦血管病、痺證 |

### （二）某些慢性病之預防

| 體質 | 易發病 | 預防 |
|---|---|---|
| 陰虛體質 | 高血壓、糖尿病 | 滋陰、節情志 |
| 陽虛體質 | 痺證、虛勞 | 溫陽、適度運動 |
| 痰濕體質 | 高血脂、高血糖 | 化濕、節飲食 |
| 氣鬱體質 | 抑鬱、月經不調 | 疏肝、調情志 |
| 血瘀體質 | 心腦血管病 | 活血、適度運動 |

## 六、治未病之三大階段

| 階段 | 對象 | 治則 |
|---|---|---|
| **未病先防** | 健康人 / 亞健康 | **養生 + 避邪** |
| **既病防變** | 已病者 | **早治 + 截斷扭轉 + 先安未受邪之地** |
| **瘥後防復** | 病後恢復期 | **慎飲食起居 + 調補正氣** |

## 註家集釋

- **王冰**注《素問·四氣調神大論》「聖人不治已病治未病」：「夫病成則難治，未病則易防，故曰治未病。」
- **張介賓**《類經·攝生類》：「**治未病者**，所以**保身全形**，故聖人之養生，必先於未病之時防之。」
- **張介賓**《類經·疾病類》：「**見肝之病，知肝傳脾，當先實脾**——此治未病之精義也。」
- **張志聰**《素問集註》：「治未病者，謂治於陰陽之偏，未發為病也。」
- **喻嘉言**《醫門法律》（後世）：「**先其所因，伏其所主**，治於未病已病之間，如此而已。」
