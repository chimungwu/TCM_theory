# 治則

> 治則者，治療疾病之法則也。**「治病必求於本」**——一切治法皆依此而立。

---

## 治則之三層結構

```
總綱（治病求本、治未病）
   │
   ├─ 標本緩急 ─── 主次先後之選擇
   ├─ 正治反治 ─── 順逆證候之變法
   ├─ 三因制宜 ─── 因時因地因人之調整
   ├─ 扶正祛邪 ─── 邪正消長之調節
   ├─ 調整陰陽 ─── 寒熱虛實之根本
   │
   └─ 八法（具體治法）—— 汗吐下和溫清消補
```

---

## 本類目錄

<div class="grid cards" markdown>

-   :material-target: **[治病求本](治病求本.md)**

    「治病必求於本」之總綱。**標本緩急、急則治標、緩則治本**——所有治則之根本依據。

-   :material-swap-horizontal: **[正治反治](正治反治.md)**

    順逆之變。**寒者熱之、熱者寒之**為正治；**塞因塞用、通因通用**為反治。

-   :material-earth: **[三因制宜](三因制宜.md)**

    **因時、因地、因人**——治療須隨時令、地域、個人體質而調整。

-   :material-shield-account: **[扶正祛邪](扶正祛邪.md)**

    調節邪正消長。「正氣存內，邪不可干」——扶正以祛邪、祛邪以安正。

-   :material-yin-yang: **[調整陰陽](調整陰陽.md)**

    「謹察陰陽所在而調之，以平為期」。損其有餘、補其不足。

-   :material-clock-time-three: **[治未病](治未病.md)**

    「聖人不治已病治未病」。**未病先防、既病防變、瘥後防復**。

-   :material-numeric-8-circle: **[八法](八法.md)**

    具體治法八大類：**汗、吐、下、和、溫、清、消、補**。每法之原理、適應與禁忌。

</div>

## 治則之關鍵原典

> 《素問·陰陽應象大論》：「**治病必求於本**。」

> 《素問·至真要大論》：「**謹察陰陽所在而調之，以平為期**。」
>
> 「**寒者熱之，熱者寒之**⋯⋯**虛者補之，實者瀉之**。」
>
> 「**逆者正治，從者反治**。」

> 《素問·四氣調神大論》：「**聖人不治已病治未病，不治已亂治未亂**。」

> 《素問·三部九候論》：「**實則瀉之，虛則補之**。」

> 《素問·標本病傳論》：「**知標本者，萬舉萬當；不知標本，是謂妄行**。」

## 與其他類別之關係

- **承自**：[病因](../病因/index.md)、[病機](../病機/index.md)（依病因病機而立法）
- **連向**：方藥（依治則選方用藥）

治則是**從理論到實踐之橋樑**——病機既明，治則自定；治則既定，方藥自出。
