# 治病求本

> **治則之總綱。** 一切治法皆從此出。

## 一、概念

> 《素問·陰陽應象大論》：「**治病必求於本**。」

「**本**」指疾病之**本質、根本原因、根本病機**；
「**標**」指疾病之**現象、表面症候、繼發病情**。

求本之法在於**辨證論治**——透過四診合參、八綱辨證、臟腑辨證等方法，把握疾病之本質。

> 《素問·三部九候論》：「**必先去其血脈，而後調之，無問其病，以平為期**。」

---

## 二、標與本之多重含義

「標本」之分依語境而異：

| 對舉 | 本 | 標 |
|---|---|---|
| **病因病果** | 病因（如感冒之風寒） | 症狀（如咳嗽、頭痛） |
| **正邪** | 正氣 | 邪氣 |
| **病位** | 內、臟、先病、原發 | 外、腑、後病、繼發 |
| **病程** | 舊病 | 新病 |
| **病機** | 病之根本機轉 | 病之表現 |
| **整體** | 整體狀態 | 局部症候 |

---

## 三、標本緩急之選擇

> 《素問·標本病傳論》：「**知標本者，萬舉萬當；不知標本，是謂妄行**⋯⋯**有其在標而求之於標，有其在本而求之於本，有其在本而求之於標，有其在標而求之於本，故治有取標而得者，取本而得者，逆取而得者，從取而得者**。」

### （一）急則治標

當**標病急重、危及生命或妨礙治本**時，先治其標。

#### 應用情境

| 情境 | 例 | 治則 |
|---|---|---|
| **大出血** | 不論何因，先止血 | 急則治標（止血） |
| **昏厥脫證** | 元氣暴脫，先回陽固脫 | 急則治標（救脫） |
| **二便閉結** | 危及生命，先通其閉 | 急則治標（通閉） |
| **高熱抽搐** | 先清熱熄風 | 急則治標（清熱） |
| **劇痛難忍** | 先止痛 | 急則治標（止痛） |

#### 治標之要

**急而後緩**——標急既解，仍當回到求本之治；不可僅止於治標。

### （二）緩則治本

**病勢平穩、無危急症狀**時，當求其本。

#### 應用情境

| 情境 | 治則 |
|---|---|
| **慢性病平穩期** | 求本治本 |
| **病後調理** | 補益固本 |
| **體質虛弱兼小病** | 調本兼治 |
| **未病先防** | 純治本（調體質） |

#### 治本之要

慢工出細活——標本兼治需時、效或徐而力遠。

### （三）標本同治

**標本並重、皆需處理**時，標本同治。

#### 應用情境

| 情境 | 例 | 標本同治之方 |
|---|---|---|
| **氣虛而表邪未解** | 體虛感冒 | 玉屏風散 + 桂枝湯（益氣解表） |
| **陰虛而便秘** | 老人陰虛便秘 | 增液承氣湯（增液瀉熱） |
| **氣陰兩虛而暑熱傷氣** | 中暑 | 白虎加人參湯（清暑益氣） |
| **正虛邪戀** | 久病不癒 | 扶正祛邪同用 |

---

## 四、求本之要訣

### （一）審證求因

從症狀（標）反推病因病機（本）。

> 《素問·至真要大論》：「**審察病機，無失氣宜**。」

### （二）辨明陰陽寒熱虛實

把握疾病之大方向——八綱辨證。

> 《素問·陰陽應象大論》：「**善診者，察色按脈，先別陰陽**。」

### （三）區別主次

複雜病情中辨清主要矛盾與次要矛盾——主要矛盾為本，次要矛盾為標。

### （四）異病同治、同病異治

| 概念 | 義 |
|---|---|
| **異病同治** | 不同疾病、若病機相同，可用同一治法（如脾虛之泄瀉、子宮下垂、胃下垂，皆可用補中益氣湯） |
| **同病異治** | 同一疾病、若病機不同，須用不同治法（如同為咳嗽，風寒、風熱、肺燥、痰濕，治法各異） |

求本之精義即在於此——**抓住病機**，而非拘於病名。

---

## 五、治則之邏輯鏈

```
症狀（標）
   ↓ 審察
病機（本）
   ↓ 立法
治則
   ↓ 選方
方藥
```

從標到本、從本到法、從法到方——「**辨證論治**」之完整鏈條。

## 六、經典出處彙集

> 《素問·陰陽應象大論》：「**治病必求於本**⋯⋯**善診者，察色按脈，先別陰陽**。」

> 《素問·標本病傳論》：「**知標本者，萬舉萬當；不知標本，是謂妄行**⋯⋯**先病而後逆者治其本，先逆而後病者治其本；先寒而後生病者治其本，先病而後生寒者治其本；先熱而後生病者治其本，先熱而後生中滿者治其標**⋯⋯**小大不利治其標，小大利治其本**。」

> 《素問·至真要大論》：「**審察病機，無失氣宜**。」

> 《素問·三部九候論》：「**實則瀉之，虛則補之**。」
