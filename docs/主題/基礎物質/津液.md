# 津液

## 一、生理

### （一）生成

> 《素問·經脈別論》：「飲入於胃，遊溢精氣，上輸於脾，脾氣散精，上歸於肺，通調水道，下輸膀胱，水精四布，五經並行，合於四時五臟陰陽，揆度以為常也。」

要義：津液源於水穀，由胃受納、脾運化、肺通調、腎主水、三焦氣化、膀胱貯泄，諸臟分工，水道通行。

### （二）津與液之別

> 《靈樞·決氣》：「腠理發泄，汗出溱溱，是謂津。」
>
> 「穀入氣滿，淖澤注於骨，骨屬屈伸，泄澤補益腦髓，皮膚潤澤，是謂液。」

**津**——清而稀薄，行於腠理皮膚，主溫潤；化為汗、淚、涕。

**液**——濁而稠厚，注於骨髓、關節、臟腑、腦髓，主滋養；化為唾、涎、骨節滑液。

津液同源而異用，異名而同類。

### （三）運行

> 《靈樞·五癃津液別》：「水穀皆入於口，其味有五，各注其海。津液各走其道，故三焦出氣，以溫肌肉，充皮膚，為其津；其流而不行者，為液。」

> 《素問·靈蘭秘典》：「三焦者，決瀆之官，水道出焉。膀胱者，州都之官，津液藏焉，氣化則能出矣。」

要義：津液運行依賴「三焦氣化」與「腎之氣化」，路徑為**胃 → 脾 → 肺 → 全身 / 腎 / 膀胱**。

### （四）功能

| 功能 | 內容 | 經典依據 |
|---|---|---|
| **滋潤** | 潤澤皮膚、孔竅、臟腑 | 《靈樞·決氣》「皮膚潤澤」 |
| **濡養** | 充骨髓、利關節、補腦 | 《靈樞·決氣》「淖澤注於骨」 |
| **化血** | 與營氣相合化生為血 | 《靈樞·癰疽》「中焦出氣如露⋯⋯化而為血」 |
| **調陰陽** | 為陰液之屬，制陽和熱 | — |
| **載藥行氣** | 為諸藥諸氣運行之憑藉 | — |

## 二、病理

### （一）傷津（津虧）

> 《素問·熱論》：「人之傷於寒也，則為病熱⋯⋯」（傷寒化熱必傷津液）

主候：口乾舌燥、皮膚乾澀、便結、尿少、舌紅少津、脈細。

### （二）脫液（傷陰）

主候：形體消瘦、舌絳光剝、目陷睛迷、煩躁手足蠕動——液為陰中之陰，傷之深者。

> 《靈樞·決氣》：「液脫者，骨屬屈伸不利，色夭，腦髓消，脛痠，耳數鳴。」

### （三）水濕內停

主候：頭重身困、肢體浮腫、納呆、便溏、舌苔白膩——濕邪困脾，水道不利。

> 《素問·至真要大論》：「諸濕腫滿，皆屬於脾。」

### （四）痰飲

津液不歸正化，停聚而成。

> 《素問·至真要大論》：「諸病水液，澄澈清冷，皆屬於寒。」

主候：咳痰、喘滿、眩暈、悸動、嘔吐清水。

### （五）水腫

> 《素問·水熱穴論》：「腎者，胃之關也，關門不利，故聚水而從其類也。」

> 《素問·湯液醪醴論》：「平治於權衡⋯⋯開鬼門，潔淨府。」（汗、利二法之原）

主候：眼瞼面目浮腫、四肢腫、按之凹陷不起。

## 三、臟象

### （一）五臟對應

| 臟 | 與津液之關係 | 主要外候 | 經典依據 |
|---|---|---|---|
| 肺 | **通調水道**、為水之上源 | 其華在毛、開竅於鼻、在液為涕 | 《素問·經脈別論》「肺朝百脈，輸精於皮毛」 |
| 脾 | **運化水濕**、轉輸津液 | 其華在唇、在液為涎 | 《素問·經脈別論》「脾氣散精」 |
| 腎 | **主水**、司氣化 | 其華在髮、開竅於耳及二陰、在液為唾 | 《素問·水熱穴論》「腎者，胃之關也」 |
| 肝 | 主疏泄，助津液輸布 | 在液為淚 | 《素問·宣明五氣》 |
| 心 | 主血脈，血為津之載 | 在液為汗 | 《素問·宣明五氣》「五臟化液⋯⋯心為汗」 |

### （二）六腑對應

- **胃**（與脾相表裡）—— 受納腐熟，為津液生成之所自始
  > 《靈樞·五味》：「胃者，五臟六腑之海也。」

- **小腸**（與心相表裡）—— 泌別清濁，分清別濁以行津液
  > 《素問·靈蘭秘典》：「小腸者，受盛之官，化物出焉。」

- **大腸**（與肺相表裡）—— 主津，吸收殘餘水液

- **膀胱**（與腎相表裡）—— **州都之官，津液藏焉**
  > 《素問·靈蘭秘典》：「膀胱者，州都之官，津液藏焉，氣化則能出矣。」

- **三焦**（孤腑）—— **決瀆之官，水道出焉**
  > 《素問·靈蘭秘典》：「三焦者，決瀆之官，水道出焉。」

### （三）經絡：是動病・所生病

擇與津液直接相關之經脈（《靈樞·經脈》）：

**手太陰肺經**

- 是主肺所生病者：咳，上氣，喘喝，煩心胸滿。

**足太陰脾經**

- 是主脾所生病者：食不下，煩心，溏瘕泄，**水閉**，黃疸，不能臥。

**足少陰腎經**

- 是動則病：飢不欲食⋯⋯心如懸若飢狀，氣不足則善恐。
- 是主腎所生病者：口熱舌乾，咽腫，上氣，嗌乾及痛，**煩心**，**心痛，黃疸**，**腸澼**。

**足太陽膀胱經**（津液之府）

- 是動則病：衝頭痛，目似脫，項如拔⋯⋯
- 是主筋所生病者：痔，瘧，狂癲疾⋯⋯

**手少陽三焦經**（決瀆之官）

- 是動則病：耳聾渾渾焞焞，嗌腫喉痺。
- 是主氣所生病者：汗出，目銳眥痛，頰痛。

## 四、治則

總綱：

> 《素問·湯液醪醴論》：「平治於權衡⋯⋯開鬼門，潔淨府，精以時服。」

| 病態 | 治則 |
|---|---|
| 傷津 | **滋陰生津、清熱保液** |
| 脫液 | **滋補腎陰、填精養液** |
| 水濕內停 | **健脾利濕、芳香化濕** |
| 痰飲 | **化痰、滌飲、溫陽**（按部位、寒熱論治） |
| 水腫 | **發汗（開鬼門）、利水（潔淨府）、溫陽化氣、健脾、補腎** |

兼顧原則：

- **三焦並調**：上焦宣肺、中焦健脾、下焦溫腎
- **氣化為要**：「氣化則津液行」——補氣化氣以行津液
- **逐水勿傷正**：利水之劑久用易傷陰，當與顧護陰液之品同用

### （二）方劑——以《湯液經法》五味補瀉解析

以**五苓散**（化氣行水之代表方）為例：

- **組成**：豬苓（甘）、茯苓（甘）、澤瀉（甘寒）、白朮（苦甘）、桂枝（辛）

- **湯液經法原則**：
  > 「脾德在緩，以甘補之，辛瀉之。」（《輔行訣》引）

- **五味結構分析**：
    - **豬苓、茯苓、澤瀉、白朮之甘**——補脾以運化水濕
    - **桂枝之辛**——一則瀉脾以行氣化、一則溫通以化膀胱之氣
    - 甘辛並用，補中有運，扶正而不滯水
    - 全方體現「化氣行水」之義——**氣化則津液行**

此方是《內經》「三焦氣化、膀胱氣化」之臨床落實，與「腎者，胃之關也」之臟象相發明。

## 註家集釋

- **王冰**注《素問·靈蘭秘典》「氣化則能出矣」：「然津液之氣，化為溺也。」
- **張介賓**《類經·藏象類》：「水穀入口⋯⋯其精微之化，則為營為衛，為津為液，為精為血。」
- **張志聰**《素問集註·經脈別論》：「飲入於胃⋯⋯此言飲食之精，五行而並行，蓋言五臟並行其精氣，相生相養而為精明。」
