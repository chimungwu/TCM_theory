## 流注次序

十二經首尾相接、晝夜流注一周：

```
肺 → 大腸 → 胃 → 脾 → 心 → 小腸 →
膀胱 → 腎 → 心包 → 三焦 → 膽 → 肝 →（復回肺）
```

對應十二時辰（子午流注）：

| 時辰 | 經 | 時辰 | 經 |
|---|---|---|---|
| 寅 | 手太陰肺 | 申 | 足太陽膀胱 |
| 卯 | 手陽明大腸 | 酉 | 足少陰腎 |
| 辰 | 足陽明胃 | 戌 | 手厥陰心包 |
| 巳 | 足太陰脾 | 亥 | 手少陽三焦 |
| 午 | 手少陰心 | 子 | 足少陽膽 |
| 未 | 手太陽小腸 | 丑 | 足厥陰肝 |

## 走向規律

> 《靈樞·逆順肥瘦》：「**手之三陰，從藏走手；手之三陽，從手走頭；足之三陽，從頭走足；足之三陰，從足走腹**。」

```
手三陰：胸 →→→ 手
手三陽：手 →→→ 頭
足三陽：頭 →→→ 足
足三陰：足 →→→ 腹胸
```

陰經陽經於四肢末端交接、於頭面交接、於胸腹交接——如環無端。
