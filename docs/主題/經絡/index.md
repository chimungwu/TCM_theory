# 經絡

> 經絡者，**運行氣血、聯絡臟腑、溝通內外、貫穿上下**之系統。

> 《靈樞·經脈》：「**經脈者，所以能決死生、處百病、調虛實，不可不通**。」

> 《靈樞·海論》：「**夫十二經脈者，內屬於腑藏，外絡於肢節**。」

## 經絡之三層結構

```
十二正經  ── 內屬臟腑、外絡肢節（運行氣血之主軸）
   │
   ├─ 手三陰：太陰肺、厥陰心包、少陰心
   ├─ 手三陽：陽明大腸、少陽三焦、太陽小腸
   ├─ 足三陽：陽明胃、少陽膽、太陽膀胱
   └─ 足三陰：太陰脾、厥陰肝、少陰腎

奇經八脈  ── 別道奇行、不直屬臟腑（調節十二經盈虛）
   │
   ├─ 任脈     主胞胎（陰脈之海）
   ├─ 督脈     貫脊上腦（陽脈之海）
   ├─ 衝脈     起於胞中（十二經之海、血海）
   ├─ 帶脈     約束諸脈
   └─ 陰維、陽維、陰蹻、陽蹻  維繫陰陽之表裡
```
