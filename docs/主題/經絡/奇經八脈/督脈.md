# 督脈

> 行於背面正中、貫脊上腦。**陽脈之海**，總督一身之陽。

## 一、循行

> 《素問·骨空論》：「**督脈者，起於少腹以下骨中央**⋯⋯其絡循陰器，合篡間⋯⋯**與太陽起於目內眥，上額交巔，上入絡腦，還出別下項**，循肩髆內，挾脊抵腰中，入循膂絡腎⋯⋯**與少陰直者，循脊裡，上至腦**。」

要義：起於少腹（胞中），其主幹貫脊裡上行、入絡腦、上至巔；又行於背面正中線。督脈**貫脊、屬腎、絡腦**。

## 二、功能

### （一）總督一身之陽——「陽脈之海」

**「督」者，總督、統率也。** 督脈行於背面正中，諸陽經（手足三陽、陽維等）皆會於督脈——故為**陽脈之總綱**，統率一身之陽經。

### （二）貫脊屬腦——與神志、髓海相關

督脈**貫脊、上至腦**——腦為髓海、元神之府。督脈為腦、脊髓與腎之間的聯繫通道，故與**神志、肢體運動、生殖**皆相關。

### （三）絡腎——與元陽相繫

督脈循脊裡而絡腎，腎為元陽之根，故督脈又主一身陽氣之根本。

## 三、相關病候

> 《素問·骨空論》：「**督脈為病，脊強反折。**」

> 《素問·骨空論》：「此生病，從少腹上衝心而痛，不得前後，為衝疝；其女子不孕，癃、痔、遺溺、嗌乾。」

| 病候 | 機理 |
|---|---|
| 脊強反折、角弓反張 | 督脈為病、貫脊失常 |
| 頭重、眩暈、健忘 | 督脈上絡腦、髓海失養 |
| 腰脊痠軟、佝僂 | 督陽不足、脊失溫煦 |
| 陽痿、不孕、遺溺 | 督脈絡腎、元陽虛衰 |
| 癲癇、神志異常 | 督脈通腦、神機失常 |

## 四、與十二經之關係

- 督脈與**任脈**相對——督行於背為陽、任行於腹為陰，二脈於唇處相接
- 督脈總會手足三陽經、陽維脈
- 與[任脈](任脈.md)、[衝脈](衝脈.md)同起於胞中（一源三歧）

## 五、經典出處彙集

> 《素問·骨空論》：「督脈者，起於少腹以下骨中央⋯⋯督脈為病，脊強反折。」

> 《素問·骨空論》：「與少陰直者，循脊裡，上至腦。」

> 《靈樞·營氣》：「上額循巔下項中⋯⋯是督脈也。」

## 註家集釋

- **王冰**注《素問·骨空論》：「督脈⋯⋯督領經脈之海也。」
- **張介賓**《類經·經絡類》：「督之為言都也，行於背部之中行，為陽脈之都綱。」
- **李時珍**《奇經八脈考》：「督乃陽脈之海⋯⋯督脈起於腎下胞中。」
