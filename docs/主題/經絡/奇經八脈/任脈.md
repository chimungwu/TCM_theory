# 任脈

> 行於腹面正中。**陰脈之海**，主胞胎。

## 一、循行

> 《素問·骨空論》：「**任脈者，起於中極之下，以上毛際，循腹裡，上關元，至咽喉，上頤循面入目。**」

要義：起於小腹（胞中），沿腹面正中線上行，至咽喉、上面、入目。

## 二、功能

### （一）總任一身之陰——「陰脈之海」

**「任」者，妊也、擔任也。** 任脈行於腹面，諸陰經（足三陰、陰維等）皆會於任脈——故為**陰脈之總匯**，統任一身之陰經。

### （二）主胞胎

> 《素問·上古天真論》：「女子⋯⋯二七而**天癸至，任脈通**，太衝脈盛，月事以時下，故有子⋯⋯七七**任脈虛**，太衝脈衰少，天癸竭，地道不通。」

要義：任脈通則月事以時下、能孕育；任脈虛則經閉、不孕——**任主胞胎**，為女子生殖之關鍵。

## 三、相關病候

> 《素問·骨空論》：「**任脈為病，男子內結七疝，女子帶下瘕聚。**」

| 病候 | 機理 |
|---|---|
| 男子七疝 | 任脈不利、寒滯下焦 |
| 女子帶下、瘕聚 | 任脈失調、衝任不固 |
| 月經不調、不孕、滑胎 | 任脈虛、不能妊養 |
| 小腹腫痛 | 任脈氣血不利 |

## 四、與十二經之關係

- 任脈與**督脈**相對——督行於背為陽，任行於腹為陰，二脈於唇處相接，構成人身陰陽之大環
- 任脈總會足三陰經、陰維脈
- 與[衝脈](衝脈.md)、[督脈](督脈.md)同起於胞中（一源三歧）

## 五、經典出處彙集

> 《素問·骨空論》：「任脈者，起於中極之下⋯⋯任脈為病，男子內結七疝，女子帶下瘕聚。」

> 《素問·上古天真論》：「二七而天癸至，任脈通⋯⋯七七任脈虛。」

> 《靈樞·五音五味》：「衝脈、任脈，皆起於胞中，上循背裡，為經絡之海。」

## 註家集釋

- **王冰**注《素問·骨空論》：「任脈⋯⋯謂陰脈之所任也。」
- **張介賓**《類經·經絡類》：「任，妊也，為人生養之本⋯⋯任脈主胞胎。」
- **李時珍**《奇經八脈考》：「任為陰脈之海，其脈起於中極之下。」
