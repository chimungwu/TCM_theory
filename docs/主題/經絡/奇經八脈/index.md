# 奇經八脈

> 別道奇行、不直屬臟腑、不相表裡之八條經脈——**調節十二經之氣血盈虛**。

---

## 「奇」之義

> 八脈別道奇行——「**奇**」者，異也、不偶也。與十二正經相異者三：

1. **不直屬臟腑**（任督衝帶等不像十二經各屬一臟一腑）
2. **無表裡配偶**（不兩兩相表裡）
3. **別道奇行**（不循十二經之常道）

要義：十二正經如江河、奇經八脈如湖澤——**正經氣血滿溢則流注奇經、正經不足則奇經補之**。奇經為十二經氣血之**調節庫**。

## 任督衝皆起於胞中

> 任、督、衝**三脈同起於胞中、一源而三歧**——又稱「**一源三歧**」。

此三脈與**生殖、月經、胎孕**關係最密，故[女子胞](../../臟腑/奇恆之腑/女子胞.md)之生理病理，實以此三脈為樞紐。
