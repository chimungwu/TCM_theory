# 帶脈

> 環腰一周，如束帶。**約束縱行諸脈**。

## 一、循行

> 《靈樞·經別》：「足少陰之正⋯⋯**當十四椎，出屬帶脈。**」

> 《難經·二十八難》：「**帶脈者，起於季脅，迴身一周。**」

要義：帶脈起於季脅（脅下），環繞腰腹一周，如束帶——是**唯一橫行之經脈**（餘經皆縱行）。

## 二、功能

### （一）約束縱行諸脈

人身十二正經與任督衝等奇經皆**縱行**——帶脈橫繞一周，**統束約制諸縱行之經**，使其各循其道、不致鬆弛。

### （二）固護胞宮、約束帶下

帶脈束於腰腹，與[女子胞](../../臟腑/奇恆之腑/女子胞.md)位置相鄰——帶脈健則約束有力、帶下正常；帶脈失約則**帶下病**作。「帶下」之名，即由帶脈而來。

## 三、相關病候

> 《素問·痿論》：「**帶脈不引**，故足痿不用也。」

> 《難經·二十九難》：「帶之為病，**腹滿，腰溶溶若坐水中**。」

| 病候 | 機理 |
|---|---|
| 帶下量多 | 帶脈失約、濕濁下注 |
| 腰腹脹滿、腰冷如坐水中 | 帶脈失調、寒濕內停 |
| 足痿不用 | 帶脈不引、宗筋失束（《素問·痿論》） |
| 子宮脫垂、滑胎 | 帶脈鬆弛、約束無力 |

## 四、與十二經之關係

- 帶脈橫束**所有縱行之經**——足三陰、足三陽、任督衝等皆受其約束
- 帶脈與**足少陰、足少陽**關係密切（出屬於足少陰之別、繫於足少陽之穴）
- 帶脈失約常與**脾虛濕盛、腎虛**並見——治帶下多從健脾、補腎、固帶入手

## 五、經典出處彙集

> 《靈樞·經別》：「足少陰之正⋯⋯當十四椎，出屬帶脈。」

> 《難經·二十八難》：「帶脈者，起於季脅，迴身一周。」

> 《難經·二十九難》：「帶之為病，腹滿，腰溶溶若坐水中。」

> 《素問·痿論》：「陽明虛則宗筋縱，帶脈不引，故足痿不用也。」

## 註家集釋

- **楊玄操**注《難經》：「帶脈者，迴身一周，猶如束帶，故名帶脈。」
- **張介賓**《類經·經絡類》：「帶脈⋯⋯所以總束諸脈，使不妄行，如人束帶而前垂。」
- **李時珍**《奇經八脈考》：「帶脈⋯⋯總束諸脈，使upright而不下陷。」（按：李氏意在「使諸脈約束而不縱弛」）
