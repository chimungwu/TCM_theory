# 標籤索引

> 依標籤反查相關主題頁。本網站採**多維度標籤體系**——同一篇主題頁通常被多個標籤索引到，便於由不同角度反查。

---

## 標籤體系

| 維度 | 內容 | 用途 |
|---|---|---|
| **臟腑** | 五臟（肝、心、脾、肺、腎）、六腑（膽、胃、小腸、大腸、膀胱、三焦）、奇恆之腑 | 反查與某臟腑相關之全部主題 |
| **基礎物質** | 氣、血、津液、精、神 | 反查物質類主題 |
| **病性** | 寒、熱、虛、實、風、濕、燥、痰飲、瘀血、氣鬱⋯ | 反查同性質之病候 |
| **五味** | 辛、甘、酸、苦、鹹 | 反查《湯液經法》組方分析 |
| **經絡** | 太陽、陽明、少陽、太陰、少陰、厥陰；衝、任、督、帶 | 反查與經絡相關之主題 |
| **病機** | 病機十九條、邪正、陰陽、升降出入⋯ | 反查病機條目 |
| **治則** | 補虛、瀉實、活血、化痰、調肝⋯ | 反查治則 |
| **疾病** | 諸病類別 | 反查疾病類專篇 |

---

## 使用方式

### 在主題頁

每篇主題頁右上角顯示其所屬標籤。點擊任一標籤——

- 跳轉到本頁、滾動到對應標籤
- 看到所有掛此標籤的主題頁列表

### 在本頁

下方為**全部標籤之反向索引**——MkDocs Material 自動匯整。標籤按字母／筆畫排序，每個標籤下列出所屬主題頁。
