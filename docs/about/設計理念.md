# 設計理念

## 緣起

現代醫學有「**生理學**」「**病理學**」「**藥理學**」「**治療學**」一系列分立又相承的學科體系。中醫雖有相應的理論層次，但散見於《內經》全篇——藏象在此、病機在彼、治則又在他處——未經現代學科化整理。

本網站嘗試以《**黃帝內經**》原文為主軸，**仿現代醫學體系**，建構中醫生理病理學的系統參考。

---

## 體系結構

### 主題式編排

每一個概念（如「血」「肝」「咳」「諸風掉眩」）**自成一篇主題頁**。基礎物質與臟腑兩類，篇內按
**生理 → 病理 → 臟象 → 治則 → 方藥** 五區塊走完一條完整路徑；其餘類別依性質另立結構（詳下節）。

外部目錄是「**主題分類**」；內部結構是「**層級展開**」。
兩者結合，使讀者可**橫向查主題、縱向看層級**。

### 類別架構

```
總論 ───────── 陰陽、五行
   │           （說理之框架，貫通全書）
   │
A. 基礎物質 ─── 氣、血、津液、精、神
   │
B. 臟腑 ─────── 五臟、六腑、奇恆之腑
   │           （生理／本體之根基）
   │
C. 經絡 ─────── 十二正經、奇經八脈
   │           （連結臟腑與外候）
   │
D. 病因 ─────── 六淫、七情、飲食勞逸、痰飲瘀血
   │           （致病因素）
   │
E. 病機 ─────── 邪正盛衰、陰陽失調、升降出入、十九條、病傳
   │           （病情之機制與轉化）
   │
F. 疾病 ─────── 《內經》專篇所及之病證
   │           （病機之具體應用）
   │
診法 ───────── 望、聞、問、切；辨證綱領
   │           （察證之法）
   │
G. 治則 ─────── 治病求本、正治反治、三因制宜、八法等
               （治療之原則與方法）
```

**總論**（陰陽、五行）為說理之框架，先於諸類而立、貫通全書。其下 A–G 七類非平行——A、B 為**體系之根**；C、D 為**病候之載體**；E 為**病機之轉化**；F 為**具體病證**；G 為**治療方法**——構成完整理論鏈。**診法**（望聞問切、辨證）介於病候與治療之間，為**察證之法**。

### 主題頁結構

主題頁依類別性質採不同結構。

**基礎物質、臟腑**兩類採五區塊：

1. **生理**——常態下的生成、運行、功能
2. **病理**——失常之形（虛實寒熱、出入升降）
3. **臟象**——與五臟、六腑、經絡（是動病・所生病）對應
4. **治則**——按病態分立之治療大法
5. **方藥**——《本經》藥物 +《湯液經法》組方分析 + 仲景延伸

**病因、病機、疾病、治則**四類，以「概念 → 分類／機理 → 治則方藥」為骨幹；**經絡**則按「循行 → 是動病 → 所生病」展開。

每篇之末皆附 **跨參照**。

## 編排原則

### 引文呈現

- **純原文加註**：不附白話翻譯，避免譯文失真
- 每段引文標明出處（如「《素問·至真要大論》」）

### 跨參照

每個主題頁之末附 **跨參照** 區，以雙向 wiki 連結指向：

- 相關主題頁（如「血」連到「氣」「精」「神」）
- 臟腑頁（如「血」連到「心」「肝」「脾」「肺」「腎」）
- 病機條目（如「諸風掉眩，皆屬於肝」）
- 治則條目（如「血實宜決之」）
- 經典出處

### 標籤系統

每頁掛上多維標籤，便於跨類檢索：

- **臟腑**：肝、心、脾、肺、腎、膽、胃、小腸、大腸、膀胱、三焦
- **病性**：寒、熱、虛、實、風、濕、燥、痰飲、瘀血、氣鬱
- **五味**：辛、甘、酸、苦、鹹（用於《湯液經法》組方分析）
- **經絡**：太陽、陽明、少陽、太陰、少陰、厥陰
- **性質**：本體（內經）／延伸（仲景）
- **出處**：素問·xx篇、靈樞·xx篇

## 不是什麼

- **不是教科書**：不從零教學、不附白話翻譯
- **不是醫案集**：不收個案、處方加減經驗
- **不是科普**：不向一般大眾簡化
- **不是訓詁專書**：不深入版本校勘的學術論證
- **不是診療指引**：所列方藥治法僅為體系說明，臨床用藥須經合格中醫師辨證

本網站定位為——

**研究者參照用之、結構化的《內經》理論索引。**

供已具備《內經》基本知識者，按主題快速反查相關概念之**體系定位、原文出處、病機歸屬、治則方藥**之網狀資源。
