# 設計理念

## 緣起

現代醫學有「生理學」「病理學」「藥理學」「治療學」一系列分立又相承的學科體系。
中醫雖有相應的理論層次，但散見於《內經》全篇，未經現代學科化整理。
本網站嘗試以《黃帝內經》原文為主軸，仿現代醫學體系，建構中醫生理病理學的系統參考。

## 主軸

**主題式編排**：每一個概念（如「血」「肝」「咳」）自成一篇主題頁，篇內按
**生理 → 病理 → 臟象 → 治則 → 方藥** 五區塊走完一條完整路徑。

外部目錄是「主題分類」（基礎物質、臟腑、經絡、病因、病機、疾病、治則），
內部結構是「層級展開」。兩者結合，使讀者可橫向查主題，也可縱向看層級。

## 編排原則

### 引文呈現

- **純原文加註**：不附白話翻譯，避免譯文失真
- 每段引文標明出處（如「《素問·至真要大論》」）
- 註家之說以脚注或獨立區塊呈現，不混入正文

### 跨參照

每個主題頁之末附 **跨參照** 區，連結至相關的：

- 主題頁（如「血」連到「氣」「精」「神」）
- 臟腑頁（如「血」連到「心」「肝」「脾」）
- 病機條目（未來擴充）
- 治則條目（未來擴充）

### 標籤系統

每頁掛上多維標籤，便於跨類檢索：

- **臟腑**：肝、心、脾、肺、腎、膽、胃、小腸、大腸、膀胱、三焦
- **病性**：寒、熱、虛、實、風、濕、燥、痰飲、瘀血、氣鬱
- **五味**：辛、甘、酸、苦、鹹（用於《湯液經法》組方分析）
- **經絡**：太陽、陽明、少陽、太陰、少陰、厥陰
- **性質**：本體（內經）／延伸（仲景）／註家
- **出處**：素問·xx篇、靈樞·xx篇

## 第一期目標

先建**架構與模板**，讓網站骨架先立得住：

1. 完整目錄樹（生理／病理／治則／方藥／原文）
2. 六種頁面模板（概念條目、臟腑專頁、病機條目、單味藥、方劑、治則）
3. 一個完整示範頁（**血**），其他主題頁按模板留白
4. C–G 類別在導航上預留位置
5. GitHub Actions 自動部署

完成後，網站結構穩定，內容可長期慢慢填。

## 不是什麼

- **不是教科書**：不從零教學，不附白話翻譯
- **不是醫案集**：不收個案、處方加減經驗
- **不是科普**：不向一般大眾簡化
- **不是訓詁專書**：不深入版本校勘的學術論證

是一個**研究者參照用的、結構化的《內經》理論索引**。
