# 註家簡介

本網站收錄之主要註家及其著作如下，未來可隨條目擴充。

## 王冰（唐）

- **生卒**：約 710–805
- **代表作**：《重廣補注黃帝內經素問》二十四卷（次注本）
- **特色**：唐代奉敕重編《素問》，補入「七篇大論」，形成今本通行篇次
- **本站定位**：**底本與第一順位註家**

## 馬蒔（明）

- **代表作**：《黃帝內經素問注證發微》《黃帝內經靈樞注證發微》
- **特色**：是**首部完整註釋《靈樞》**之專著，重視循經訓詁
- **本站定位**：《靈樞》部分之主要註家

## 張介賓（明）

- **字會卿，號景岳**
- **代表作**：《類經》《類經圖翼》《景岳全書》
- **特色**：將《素問》《靈樞》合編，按攝生、陰陽、藏象、脈色、經絡、標本、氣味、論治、疾病、針刺、運氣、會通**十二類**重編，是**主題式重編《內經》之集大成**
- **本站定位**：藏象、論治類之主要參照

## 張志聰（清）

- **字隱庵**
- **代表作**：《黃帝內經素問集註》《黃帝內經靈樞集註》
- **特色**：清代會通諸家之集註本，以氣化論貫通解經
- **本站定位**：氣化、陰陽論之主要參照

## 高世栻（清）

- **代表作**：《黃帝素問直解》
- **特色**：力求文義淺顯而不失古義
- **本站定位**：訓詁參照

## 丹波元簡（日，江戶）

- **代表作**：《素問識》《靈樞識》
- **特色**：考據精審，廣引中日諸註，為清末以後諸家所重
- **本站定位**：考證疑難條目時參照

---

## 註家收錄原則

1. **王冰注必收**（凡《素問》原文有王冰注者）
2. 其他註家**按條目精選**：哪一條註得好就引哪一家，非條條皆收
3. 註家之間有歧義時並列，不強為調和
4. 引註家原文，加註家姓名與書名以為區隔，不混入正文按語
