## 填寫須知

1. **任一區塊暫缺時**：寫 `> 待補` 即可，不可省略區塊
2. **引文先列，按語後綴**：原文用 blockquote，後接精簡按語，**不附白話翻譯**
3. **王冰注隨原文附之**，緊接引文之下
4. **延伸區**（仲景方）必須明確標示，不可與本體混淆
5. **標籤**從固定詞表選用（見[設計理念](../about/設計理念.md)）
