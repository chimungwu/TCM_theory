# 引文體例

本網站之引文格式統一規範如下，方便讀者辨識來源、層級與性質。

## 引文標示

### 一、《內經》原文

直接以 `>` blockquote 引出，篇名置於引號之前：

```markdown
> 《素問·至真要大論》：「謹察陰陽所在而調之，以平為期。」
```

呈現效果：

> 《素問·至真要大論》：「謹察陰陽所在而調之，以平為期。」

### 二、王冰注

緊接原文之下，以「**王冰注**」起首：

```markdown
> 《靈樞·決氣》：「中焦受氣取汁，變化而赤，是謂血。」

王冰注：「中焦受谷之氣取其汁液，奉心化赤，變而為血。」
```

### 三、其他註家

以註家姓名 + 著作開頭：

```markdown
**張介賓**《類經·藏象類》：「血之與氣，異名同類。」
**張志聰**《靈樞集註·決氣篇》：「中焦取汁奉心化赤而為血者，乃陽中之陰也。」
```

### 四、延伸內容（仲景經方等）

在區塊起首明確標示：

```markdown
> 以下屬《傷寒》《金匱》體系，超出《內經》本體，列為**延伸**參考。
```

## 篇名簡寫對照

為求精準，本站不採簡寫，篇名一律全稱：

| 全稱 | 不採用之簡寫 |
|---|---|
| 《素問·上古天真論》 | 《上古》 |
| 《靈樞·經脈》 | 《經脈篇》 |
| 《素問·至真要大論》 | 《至真要》 |

## 主題頁結構規範

每一主題頁固定五區塊，不可省略，但任一區塊內容暫缺時可注明「待補」：

```markdown
# 主題名

## 一、生理
（未填內容時：> 待補）

## 二、病理
## 三、臟象
### （一）五臟對應
### （二）六腑對應
### （三）經絡：是動病・所生病
## 四、治則
## 五、方藥
### （一）代表藥物（《神農本草經》）
### （二）方劑——以《湯液經法》五味補瀉解析
### （三）延伸：仲景經方
```

之後固定接：

```markdown
## 註家集釋
## 跨參照
## 標籤
```

## 表格規範

### 五臟對應表

| 臟 | 與主題之關係 | 主要外候 | 經典依據 |
|---|---|---|---|

### 經絡是動・所生病

採「經名 → 是動 → 所生」三段結構，不混為一段：

```markdown
**手少陰心經**

- 是動則病：嗌乾、心痛、渴而欲飲。
- 是主心所生病者：目黃、脅痛、臑臂內後廉痛厥、掌中熱痛。
```

### 《本經》藥物表

| 藥 | 三品 | 氣味 | 《本經》主治擇要 |
|---|---|---|---|

主治直引《本經》原文（節略時用「…」），不改寫。

### 仲景方表（延伸區）

| 方 | 出處 | 病機 | 治則對應 |
|---|---|---|---|

## 跨參照寫法

採 wiki link 風格：

```markdown
- 主題：[氣](../基礎物質/氣.md) / [津液](../基礎物質/津液.md)
- 臟象：[心](../臟腑/五臟/心.md) / [肝](../臟腑/五臟/肝.md)
```

## 標籤寫法

每頁末以行內 code 列出：

```markdown
`基礎物質` `心` `肝` `脾` `肺` `衝脈` `辛` `甘` `酸` `補血` `活血`
```

未來會自動轉成標籤頁的反向索引。
