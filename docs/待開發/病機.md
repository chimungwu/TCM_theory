# 病機（二期擴充）

!!! info "二期內容"
    本類別屬第一期之後的擴充內容，現正規劃中，敬請期待。

## 規劃內容

- 邪正盛衰
- 陰陽失調（偏盛、偏衰、互損、格拒、亡失）
- 氣血津液失常
- 升降出入失常
- 病機十九條（《素問·至真要大論》）
- 病傳：表裡、臟腑、經絡傳變（《素問·玉機真藏論》《素問·熱論》）


## 為何放在二期

第一期聚焦於**基礎物質**與**臟腑**——這兩類是其他一切類別的基礎。
本類別需以這些基礎為前提才能展開，故先架其位於導航，內容隨後填入。
