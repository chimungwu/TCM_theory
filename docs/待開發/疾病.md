# 疾病（二期擴充）

!!! info "二期內容"
    本類別屬第一期之後的擴充內容，現正規劃中，敬請期待。

## 規劃內容

依《內經》專篇所及之疾病：

- 咳論（《素問·咳論》：五臟六腑皆令人咳）
- 痺論（《素問·痺論》：行痺、痛痺、著痺）
- 痿論（《素問·痿論》：五痿）
- 厥論（《素問·厥論》）
- 舉痛論（《素問·舉痛論》）
- 風論、瘧論、熱論、消渴、水熱穴論等


## 為何放在二期

第一期聚焦於**基礎物質**與**臟腑**——這兩類是其他一切類別的基礎。
本類別需以這些基礎為前提才能展開，故先架其位於導航，內容隨後填入。
