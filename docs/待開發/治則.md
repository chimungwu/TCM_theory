# 治則（二期擴充）

!!! info "二期內容"
    本類別屬第一期之後的擴充內容，現正規劃中，敬請期待。

## 規劃內容

- 治病求本
- 標本緩急
- 正治反治（《素問·至真要大論》）
- 三因制宜（因時、因地、因人）
- 八法雛形：汗、吐、下、和、溫、清、消、補
- 「血實宜決之」「氣虛宜掣引之」之類具體治則彙整


## 為何放在二期

第一期聚焦於**基礎物質**與**臟腑**——這兩類是其他一切類別的基礎。
本類別需以這些基礎為前提才能展開，故先架其位於導航，內容隨後填入。
